1. அடிப்படைத் தகவல்கள்
  • மனிதர்கள், சூழலியல் அமைப்புகள் மற்றும் பொருளாதார நடவடிக்கைகளுக்கு பயன்படுத்தக்கூடிய இயற்கையாகக் கிடைக்கும் அனைத்து நீர்வளங்களும் நீர்வளங்கள் எனப்படும்.
  • முக்கிய மூலங்கள்:
  • ஆறுகள்.
  • ஏரிகள்.
  • நீர்த்தேக்கங்கள்.
  • நிலத்தடி நீர்.
  • பனிப்பாறைகள் மற்றும் பனி.
  • ஈரநிலங்கள்.
  • மழைநீர்.
  • நீர் புதுப்பிக்கத்தக்க வளம் என்றாலும், பயன்படுத்தக்கூடிய நன்னீர் அளவு குறைவாகவும் சமமற்ற வகையில் பகிர்ந்தளிக்கப்பட்டும் உள்ளது.
🔗 TNPSC Key Link

நீர்வளம் → புதுப்பிக்கத்தக்கது, ஆனால் அளவு குறைவு மற்றும் சமமற்ற பகிர்வு

2. பூமியில் நீரின் பகிர்வு
  • பூமியின் பெரும்பாலான நீர் உப்புநீராக இருந்து கடல்கள் மற்றும் பெருங்கடல்களில் காணப்படுகிறது.
  • நன்னீர் மிகச் சிறிய பகுதியே ஆகும்.
  • நன்னீரின் பெரும்பகுதி பனிப்பாறைகள், பனிக்கவசங்கள் மற்றும் நிலத்தடி நீரில் சேமிக்கப்பட்டுள்ளது.
  • ஆறுகள் மற்றும் ஏரிகளில் எளிதாகக் கிடைக்கும் நன்னீர், உலகின் மொத்த நீர்வளத்தில் மிகச் சிறிய பகுதியே ஆகும்.
⚠️ TNPSC Trap

பூமியில் நீர் அதிகமாக இருந்தாலும், நேரடியாகப் பயன்படுத்தக்கூடிய நன்னீர் குறைவாக உள்ளது.

3. இந்தியாவின் நன்னீர் மூலங்கள்
  • இந்தியாவின் நன்னீர் முக்கியமாக பெறப்படுவது:
  • பருவமழை.
  • இமயமலைப் பனி மற்றும் பனிப்பாறைகள்.
  • ஆறுகள்.
  • நிலத்தடி நீர்.
  • ஏரிகள் மற்றும் நீர்த்தேக்கங்கள்.
  • ஈரநிலங்கள்.
4. பருவமழையின் முக்கியத்துவம்
  • இந்தியாவின் நன்னீர் மீள்நிரப்பலுக்கான முக்கிய ஆதாரம் பருவமழை ஆகும்.
  • இது பின்வற்றை மீள்நிரப்புகிறது:
  • ஆறுகள்.
  • நீர்த்தேக்கங்கள்.
  • குளங்கள்.
  • ஏரிகள்.
  • நிலத்தடி நீர்.
  • மண் ஈரப்பதம்.
  • பலவீனமான பருவமழை ஆண்டுகள் பல நீர்மூலங்களையும் ஒரே நேரத்தில் பாதிக்கக்கூடும்.
5. சமமற்ற நீர் கிடைப்புத் தன்மை
  • நீர் கிடைப்பில் வேறுபாடு ஏற்படுவதற்கான காரணங்கள்:
  • மழைப்பொழிவு.
  • ஆற்று அமைப்புகள்.
  • புவியியல் அமைப்பு.
  • நிலத்தோற்றம்.
  • மக்கள்தொகை.
  • நிலத்தடி நீர் மீள்நிரப்பு.
  • சேமிப்பு திறன்.
  • சில பகுதிகள் வெள்ளத்தைச் சந்திக்கின்றன; மற்ற பகுதிகள் நீடித்த நீர்ப்பற்றாக்குறையை எதிர்கொள்கின்றன.
6. நீர் கிடைப்பின் பருவகால தன்மை
  • இந்தியாவின் மழைப்பொழிவில் பெரும்பகுதி சில பருவமழை மாதங்களிலேயே கிடைக்கிறது.
  • எனவே பல ஆற்றுப்படுகைகளில் ஆற்றோட்டம் பருவகாலத்தை மிகவும் சார்ந்துள்ளது.
  • வறண்ட காலப் பயன்பாட்டிற்காக பருவமழை நீரைச் சேமிக்க சேமிப்பு கட்டமைப்புகள் தேவைப்படுகின்றன.
🔗 TNPSC Key Link

இந்தியாவின் நீர் சவால் → சில மாதங்களில் மழை அதிகமாகக் குவிவது

7. மேற்பரப்பு நீர்
  • மேற்பரப்பு நீரில் அடங்குபவை:
  • ஆறுகள்.
  • ஓடைகள்.
  • ஏரிகள்.
  • குளங்கள்.
  • நீர்த்தேக்கங்கள்.
  • குளங்கள்.
  • ஈரநிலங்கள்.
  • இவை ஆவியாதல், மாசுபாடு மற்றும் பருவகால ஏற்றத்தாழ்வுகளுக்கு நேரடியாக உள்ளாகின்றன.
8. நிலத்தடி நீர்
  • பூமியின் மேற்பரப்புக்குக் கீழே உள்ள துளைகள், பிளவுகள் மற்றும் பாறை அமைப்புகளில் சேமிக்கப்பட்டுள்ள நீரே நிலத்தடி நீர்.
  • இது முக்கிய ஆதாரமாக இருப்பவை:
  • பாசனம்.
  • குடிநீர்.
  • கிராமப்புற வீட்டு நீர்வழங்கல்.
  • நகர்ப்புற நீர்வழங்கல்.
  • அளவுக்கு மீறிய எடுப்பு கடுமையான நீர்வளக் குறைப்பை ஏற்படுத்தலாம்.
9. நிலத்தடி நீர்மட்டம்
  • நிலத்தடி நீர் முழுமையாக நிரம்பிய பகுதியின் மேல்பரப்பே நீர்மட்டம்.
  • மீள்நிரப்பு ஏற்பட்ட பிறகு இது உயரும்.
  • மீள்நிரப்பை விட வேகமாக நிலத்தடி நீர் எடுக்கப்பட்டால் இது குறையும்.
📌 Must-Memorise

நிலத்தடி நீரின் மேற்பரப்பு → நீர்மட்டம்

10. செறிவூட்டப்பட்ட மண்டலம்
  • நீர்மட்டத்திற்குக் கீழே உள்ள துளைகள் மற்றும் பிளவுகள் நீரால் நிரம்பியிருக்கும்.
  • இந்தப் பகுதி செறிவூட்டப்பட்ட மண்டலம் எனப்படுகிறது.
11. காற்றோட்ட மண்டலம்
  • நீர்மட்டத்திற்கு மேலுள்ள பகுதியில் மண் மற்றும் பாறைத் துளைகளில் காற்றும் நீரும் இரண்டும் காணப்படும்.
  • இது செறிவூட்டப்படாத மண்டலம் என்றும் அழைக்கப்படுகிறது.
12. அக்விஃபர்
  • நிலத்தடி நீரைச் சேமித்து கடத்தக்கூடிய ஊடுருவக்கூடிய புவியியல் அமைப்பே அக்விஃபர்.
  • மணல், சரளை மற்றும் பிளவுபட்ட பாறைகள் நல்ல நீர்தாங்கி அக்விஃபர்களாக அமையலாம்.
📌 Must-Memorise

அக்விஃபர் → நிலத்தடி நீரைச் சேமிக்கும் + கடத்தும்

13. அக்விக்ளூட்
  • அக்விக்ளூட் நீரைச் சேமிக்க முடியும்; ஆனால் அதை மிக மெதுவாகவே கடத்தும்.
  • களிமண் அதிகமுள்ள அமைப்புகள் பொதுவான உதாரணங்கள்.
14. அக்விட்டார்ட்
  • அக்விட்டார்ட் ஒரு நல்ல அக்விஃபரை விட நீரை மெதுவாகக் கடத்தும்.
  • இது நிலத்தடி நீரின் இயக்கத்தை கட்டுப்படுத்தக்கூடும்.
15. அடைக்கப்பட்ட அக்விஃபர்
  • அடைக்கப்பட்ட அக்விஃபர் ஒப்பீட்டளவில் நீர் ஊடுருவாத அடுக்குகளுக்கிடையே அமைந்திருக்கும்.
  • இதிலுள்ள நிலத்தடி நீர் அழுத்தத்தில் இருக்கும்.
  • அதைத் துளைக்கும் கிணற்றில், அக்விஃபரின் மேல்பரப்பை விட நீர் மேலே உயரக்கூடும்.
16. அடைக்கப்படாத அக்விஃபர்
  • அடைக்கப்படாத அக்விஃபரின் மேல் நீர் ஊடுருவாத அடுக்கு இருக்காது.
  • இதன் மேல்புற எல்லை நீர்மட்டமாகும்.
  • மேற்பரப்பிலிருந்து நீர் ஊடுருவுவதன் மூலம் இது நேரடியாக மீள்நிரப்பப்படுகிறது.
17. ஆர்டீசியன் கிணறு
  • ஆர்டீசியன் கிணறு ஒரு அடைக்கப்பட்ட அக்விஃபரிலிருந்து நீரைப் பெறுகிறது.
  • அழுத்தம் காரணமாக கிணற்றில் நீர் இயற்கையாக மேலே உயரலாம்.
  • சில நேரங்களில் பம்ப் செய்யாமலேயே நீர் மேற்பரப்பிற்கு பாயக்கூடும்.
🔗 TNPSC Key Link

ஆர்டீசியன் கிணறு → அடைக்கப்பட்ட அக்விஃபர் + அழுத்தம்

18. நிலத்தடி நீர் மீள்நிரப்பு
  • நிலத்தடி நீர் மீள்நிரப்பு பின்வரும் வழிகளில் நடைபெறுகிறது:
  • மழைநீர் ஊடுருவல்.
  • ஆற்றுநீர் கசிவு.
  • குளம் மற்றும் ஏரிநீர் கசிவு.
  • பாசனத்திலிருந்து மீளும் நீர்.
  • செயற்கை மீள்நிரப்பு கட்டமைப்புகள்.
19. ஊடுருவல்
  • மேற்பரப்பிலுள்ள நீர் மண்ணுக்குள் நுழையும் செயலே ஊடுருவல்.
  • நீர் ஊடுருவக்கூடிய மண்ணும் தாவர மூடலும் ஊடுருவலை அதிகரிக்கின்றன.
  • கான்கிரீட் மேற்பரப்புகள் ஊடுருவலைக் குறைக்கின்றன.
20. கீழ்ஊடுருவல்
  • மண்ணுக்குள் நுழைந்த நீர் மண் மற்றும் பாறைகள் வழியாக கீழ்நோக்கி நகர்வதே கீழ்ஊடுருவல்.
  • இது ஆழமான நிலத்தடி நீரை மீள்நிரப்ப உதவுகிறது.
21. நிலத்தடி நீர் மீள்நிரப்பை பாதிக்கும் காரணிகள்
  • மீள்நிரப்பு சார்ந்திருப்பவை:
  • மழையின் தீவிரம்.
  • மண் அமைப்பு.
  • பாறையின் ஊடுருவும் தன்மை.
  • தாவர மூடல்.
  • சாய்வு.
  • நிலப் பயன்பாடு.
  • மழை நீடிக்கும் காலம்.
22. வண்டல் அக்விஃபர்கள்
  • வட இந்திய சமவெளிகளில் விரிவான வண்டல் அக்விஃபர்கள் உள்ளன.
  • மணல் மற்றும் சரளை அடுக்குகள் பெரிய அளவு நிலத்தடி நீரைச் சேமிக்கின்றன.
  • குழாய்க் கிணறு பாசனம் பரவலாகப் பயன்படுத்தப்படுகிறது.
🔗 TNPSC Key Link

வட இந்திய சமவெளிகள் → முக்கிய வண்டல் நிலத்தடி நீர் அக்விஃபர்கள்

23. கடினப் பாறை அக்விஃபர்கள்
  • தீபகற்ப இந்தியாவின் பெரும்பகுதியில் கடினமான படிகப் பாறைகள் காணப்படுகின்றன.
  • நிலத்தடி நீர் முக்கியமாகக் காணப்படும் இடங்கள்:
  • வானிலையால் சிதைந்த பகுதிகள்.
  • இணைப்புகள்.
  • பிளவுகள்.
  • முறிவுகள்.
  • தடித்த வண்டல் அக்விஃபர்களுடன் ஒப்பிடும்போது, இங்கு நீர் சேமிப்பு பொதுவாகக் குறைவாகவும் குறிப்பிட்ட இடங்களிலேயே காணப்படுவதுமானதாகும்.
24. தமிழ்நாட்டின் நிலத்தடி நீர்
  • தமிழ்நாட்டின் பெரும்பகுதியில் கடினப் பாறை அக்விஃபர்கள் உள்ளன.
  • மாவட்டங்களுக்கு இடையே நிலத்தடி நீர் கிடைப்பில் கணிசமான வேறுபாடு உள்ளது.
  • வானிலையால் சிதைந்த மற்றும் பிளவுபட்ட படிகப் பாறைகள் முக்கிய நிலத்தடி நீர் மண்டலங்களாகும்.
  • கடலோர அக்விஃபர்களில் கடல்நீர் ஊடுருவும் அபாயம் உள்ளது.
25. நிலத்தடி நீரை அளவுக்கு மீறி எடுத்தல்
  • அளவுக்கு மீறி நிலத்தடி நீர் எடுப்பதால்:
  • நீர்மட்டம் குறைதல்.
  • கிணறுகள் வறண்டு போதல்.
  • பம்ப் செலவு அதிகரித்தல்.
  • சில இடங்களில் நிலம் தாழ்தல்.
  • ஆறுகளுக்கான அடியோட்டம் குறைதல்.
  • கடலோரப் பகுதிகளில் கடல்நீர் ஊடுருவல்.
26. கடல்நீர் ஊடுருவல்
  • கடலோரப் பகுதிகளில் அளவுக்கு மீறி நிலத்தடி நீரை எடுத்தால் நன்னீரின் அழுத்தம் குறையலாம்.
  • பின்னர் கடல்நீர் கடலோர அக்விஃபர்களுக்குள் நுழையும்.
  • இதனால் நிலத்தடி நீர் உப்புத்தன்மை பெறும்.

27. நிலத்தடி நீரின் தரம்
  • நிலத்தடி நீர் பின்வற்றால் பாதிக்கப்படலாம்:
  • உப்புத்தன்மை.
  • ஃப்ளூரைடு.
  • ஆர்செனிக்.
  • நைட்ரேட்.
  • இரும்பு.
  • தொழிற்சாலை மாசுபாடு.
  • கழிவுநீர் மாசுபாடு.
28. நிலத்தடி நீரில் ஃப்ளூரைடு
  • குடிநீரில் அதிக ஃப்ளூரைடு இருந்தால் ஃப்ளூரோசிஸ் ஏற்படலாம்.
  • பல் ஃப்ளூரோசிஸ் பற்களை பாதிக்கும்.
  • எலும்பு ஃப்ளூரோசிஸ் எலும்புகள் மற்றும் மூட்டுகளை பாதிக்கும்.

29. ஆர்செனிக் மாசுபாடு
  • கங்கை–பிரம்மபுத்திரா வண்டல் சமவெளிகளின் சில பகுதிகளில் ஆர்செனிக் மாசுபாடு ஒரு கடுமையான நிலத்தடி நீர் பிரச்சினையாகும்.
  • நீண்டகாலம் இதற்கு உட்படுதல் கடுமையான உடல்நலப் பிரச்சினைகளை ஏற்படுத்தலாம்.
30. நைட்ரேட் மாசுபாடு
  • நைட்ரேட் நிலத்தடி நீருக்குள் நுழையும் மூலங்கள்:
  • உரங்கள்.
  • கழிவுநீர்.
  • விலங்கு கழிவுகள்.
  • குடிநீரில் அதிக நைட்ரேட் இருப்பது, குறிப்பாக குழந்தைகளில் மெத்தீமோகுளோபினீமியா நோயை ஏற்படுத்தலாம்.
31. நீர்ப்பற்றாக்குறை
  • நீர்ப்பற்றாக்குறை ஏற்படும் நிலைகள்:
  • நீர் தேவை கிடைக்கும் அளவை மீறும்போது.
  • இயற்கையாகவே நீர் கிடைக்காதபோது.
  • நீர் தரம் குறைவதால் கிடைக்கும் நீரைப் பயன்படுத்த முடியாதபோது.
  • கட்டமைப்பு வசதிகள் நீரைச் சரியாக வழங்க முடியாதபோது.
32. இயற்கை நீர்ப்பற்றாக்குறை
  • இயற்கையாகக் கிடைக்கும் நீர் தேவையைப் பூர்த்தி செய்ய போதாத பகுதிகளில் இயற்கை நீர்ப்பற்றாக்குறை ஏற்படும்.
  • வறண்ட மற்றும் வறட்சிப் பாதிப்பு அதிகமுள்ள பகுதிகள் குறிப்பாக பாதிக்கப்படுகின்றன.
33. பொருளாதார நீர்ப்பற்றாக்குறை
  • நீர் இருப்பினும் அதை வழங்க தேவையான கட்டமைப்பு, நிதி அல்லது நிர்வாக அமைப்புகள் போதாமையால் ஏற்படுவது பொருளாதார நீர்ப்பற்றாக்குறை.
34. இந்தியாவில் நீர்ப்பற்றாக்குறைக்கான காரணங்கள்
  • முக்கிய காரணங்கள்:
  • சமமற்ற மழைப்பொழிவு.
  • மக்கள்தொகை வளர்ச்சி.
  • நகர்மயமாக்கல்.
  • பாசனத் தேவை.
  • நிலத்தடி நீர் குறைதல்.
  • மாசுபாடு.
  • போதிய சேமிப்பு இல்லாமை.
  • கசிவு மற்றும் வீணாக்கம்.
  • காலநிலை மாறுபாடு.
35. வேளாண்மை மற்றும் நீர் பயன்பாடு
  • இந்தியாவில் அதிக நீரைப் பயன்படுத்தும் துறை வேளாண்மை.
  • நன்னீர் எடுப்பில் மிகப் பெரிய பங்கு பாசனத்திற்காகப் பயன்படுத்தப்படுகிறது.
  • அதிக நீர் தேவைப்படும் பயிர்கள் நீர்வளத்தின் மீது கூடுதல் அழுத்தம் ஏற்படுத்துகின்றன.
36. பாசனம்
  • பயிர்களுக்கு செயற்கையாக நீர் வழங்குவதே பாசனம்.
  • இது மழையைப் பூர்த்திசெய்யவோ அல்லது மாற்றாகச் செயல்படவோ செய்கிறது.
  • பின்வரும் பகுதிகளில் இது அவசியம்:
  • குறைந்த மழைப்பொழிவு.
  • நிலையற்ற மழைப்பொழிவு.
  • வறண்ட காலப் பயிரிடல்.
37. பாசனத்தின் முக்கிய மூலங்கள்
  • இந்தியாவில் பயன்படுத்தப்படுபவை:
  • கால்வாய்கள்.
  • கிணறுகள்.
  • குழாய்க் கிணறுகள்.
  • குளங்கள்.
  • நீர்த்தேக்கங்கள்.
  • தூக்குப் பாசனம்.
  • நுண்ணீர்ப்பாசன அமைப்புகள்.
38. கால்வாய் பாசனம்
  • கால்வாய்கள் ஆறு அல்லது நீர்த்தேக்க நீரை வேளாண் நிலங்களுக்கு கொண்டு செல்கின்றன.
  • வட இந்திய சமவெளிகளிலும் பெரிய கட்டுப்பாட்டு பாசனப் பகுதிகளிலும் கால்வாய் பாசனம் முக்கியமானது.
39. ஆண்டு முழுவதும் நீர்வரும் கால்வாய்
  • நிரந்தர ஆறு அல்லது நீர்த்தேக்கத்திலிருந்து ஆண்டு பெரும்பகுதியில் ஒழுங்குபடுத்தப்பட்ட நீரைப் பெறும் கால்வாயே ஆண்டு முழுவதும் நீர்வரும் கால்வாய்.
40. வெள்ளக்கால கால்வாய்
  • ஆற்றில் நீர்ப்பாய்ச்சி அதிகமாக இருக்கும் காலங்களில் வெள்ளக்கால கால்வாய்கள் நீரை எடுக்கின்றன.
  • பாரம்பரியமாக இவை பெரும்பாலும் வெள்ள காலங்களில் செயல்படுகின்றன.
41. கிணறு பாசனம்
  • கிணறுகள் ஆழமற்ற நிலத்தடி நீரைப் பெறுகின்றன.
  • நிலத்தடி நீர் எளிதில் கிடைக்கும் வண்டல் மற்றும் கடினப் பாறை பகுதிகளில் இவை பரவலாகப் பயன்படுத்தப்படுகின்றன.
42. குழாய்க் கிணறுகள்
  • துளையிடப்பட்ட குழாய்கள் மூலம் குழாய்க் கிணறுகள் நிலத்தடி நீரைப் பெறுகின்றன.
  • பம்ப் மூலம் பெரிய அளவு நீரை எடுக்க முடியும்.
  • வட இந்திய வண்டல் சமவெளிகளில் இவை குறிப்பாக அதிகம் காணப்படுகின்றன.
43. குளப் பாசனம்
  • குளங்கள் மழைநீர் மற்றும் மேற்பரப்பு ஓட்டத்தைச் சேமிக்கின்றன.
  • தீபகற்ப இந்தியாவில் குளப் பாசனத்திற்கு நீண்ட வரலாற்று முக்கியத்துவம் உள்ளது.
  • தமிழ்நாட்டில் விரிவான பாரம்பரிய குள அமைப்பு உள்ளது.

44. தீபகற்ப இந்தியாவில் குளங்கள் ஏன் முக்கியம்?
  • காரணங்கள்:
  • அலைபோன்ற நிலத்தோற்றம்.
  • பருவகால ஆறுகள்.
  • கடினப் பாறை புவியியல்.
  • இயற்கை தாழ்வுகள்.
  • மழை சில பருவங்களில் அதிகமாகக் குவிவது.
45. தமிழ்நாட்டின் குளப் பாசனம்
  • குளங்கள் பருவமழை மேற்பரப்பு ஓட்டத்தைச் சேகரிக்கின்றன.
  • நம்பகமான நிரந்தர ஆறுகள் இல்லாத பகுதிகளில் இவை வேளாண்மையை ஆதரிக்கின்றன.
  • பல குளங்கள் தொடர் அமைப்பாக ஒன்றோடொன்று இணைக்கப்பட்டுள்ளன.
  • இவை நிலத்தடி நீரையும் மீள்நிரப்புகின்றன.
46. ஏரி அமைப்பு
  • தமிழ்நாட்டின் பாரம்பரிய பாசனக் குளங்கள் பொதுவாக ‘ஏரி’ என்று அழைக்கப்படுகின்றன.
  • ஏரி அமைப்புகள் மழைநீர் மற்றும் ஆற்றின் மேற்பரப்பு ஓட்டத்தைச் சேமிக்கின்றன.
  • இவை நீண்டகாலமாக நெல் சாகுபடி மற்றும் கிராம நீர் மேலாண்மையை ஆதரித்துள்ளன.

  • இதனால் நீர் பயன்பாடும் நிலத்தடி நீர் மீள்நிரப்பும் மேம்படும்.
48. தூக்குப் பாசனம்
  • பம்புகளைப் பயன்படுத்தி தாழ்ந்த இடத்திலிருந்து உயர்ந்த வேளாண் நிலத்திற்குத் தண்ணீரை உயர்த்திக் கொடுப்பதே தூக்குப் பாசனம்.
  • ஈர்ப்பு விசை மூலம் நீர் பாய்ச்சி சாத்தியமில்லாத இடங்களில் இது பயனுள்ளது.
49. நுண்ணீர்ப்பாசனம்
  • நுண்ணீர்ப்பாசனத்தில் அடங்குபவை:
  • சொட்டு நீர்ப்பாசனம்.
  • தெளிப்பு நீர்ப்பாசனம்.
  • இந்த முறைகள் நீர் பயன்பாட்டு திறனை அதிகரிப்பதைக் குறிக்கோளாகக் கொண்டுள்ளன.
50. சொட்டு நீர்ப்பாசனம்
  • சொட்டு நீர்ப்பாசனம் தாவர வேர்களுக்கு அருகே நேரடியாக நீரை வழங்குகிறது.
  • குழாய்கள் மற்றும் வெளியீட்டுக் கருவிகள் மூலம் சிறிய அளவில் நீர் வழங்கப்படுகிறது.
  • ஆவியாதல் மற்றும் கடத்தல் இழப்புகள் குறைக்கப்படுகின்றன.

51. சொட்டு நீர்ப்பாசனத்திற்கு ஏற்ற பயிர்கள்
  • சொட்டு நீர்ப்பாசனம் ஏற்றவை:
  • பழப்பயிர்கள்.
  • காய்கறிகள்.
  • கரும்பு.
  • பருத்தி.
  • தோட்டப் பயிர்கள்.
52. தெளிப்பு நீர்ப்பாசனம்
  • அழுத்தமுள்ள குழாய்கள் மற்றும் நாசில்கள் வழியாக தெளிப்பு நீர்ப்பாசனம் நீரைப் பகிர்ந்தளிக்கிறது.
  • செயற்கை மழையைப் போல நீர் பயிர்களின் மீது விழும்.
  • சமமற்ற நிலங்களிலும் மணற்பாங்கான மண்ணிலும் இது பயனுள்ளது.
53. சொட்டு நீர்ப்பாசனம் vs தெளிப்பு நீர்ப்பாசனம்
  • சொட்டு:
  • வேர் மண்டலத்தில் நீர் வழங்கல்.
  • மிக உயர்ந்த நீர் பயன்பாட்டு திறன்.
  • இடைவெளி அதிகமுள்ள பயிர்களுக்கு மிகவும் ஏற்றது.
  • தெளிப்பு:
  • புலம் முழுவதும் தெளிக்கிறது.
  • சமமற்ற நிலங்களில் பயனுள்ளது.
  • பல புலப் பயிர்களுக்கு ஏற்றது.
54. வெள்ளப் பாசனம்
  • நீர் வயல்களின் மேல் பாய அனுமதிக்கப்படுகிறது.
  • இது எளிய முறை; ஆனால் பின்வற்றால் நீர் இழப்பு அதிகமாக இருக்கலாம்:
  • ஆவியாதல்.
  • மேற்பரப்பு ஓட்டம்.
  • ஆழமான கீழ்ஊடுருவல்.
  • தவறாக நிர்வகிக்கப்படும் வெள்ளப் பாசனம் நீர்த்தேக்கம் மற்றும் உப்புத்தன்மையை ஏற்படுத்தலாம்.
55. நீர்த்தேக்கம்
  • நீர்மட்டம் மண் மேற்பரப்பிற்கு அருகே உயரும்போது நீர்த்தேக்கம் ஏற்படும்.
  • மண் துளைகள் நீரால் நிரம்பிவிடும்.
  • வேர்களுக்கு காற்றோட்டம் குறையும்.
  • பயிர் உற்பத்தித்திறன் குறையலாம்.
56. பாசனத்தால் மண் உப்புத்தன்மை
  • வடிகால் வசதி குறைந்த பகுதிகளில் அதிகப்படியான பாசனம் நீர்மட்டத்தை உயர்த்தலாம்.
  • ஆவியாதலால் உப்புகள் மண் மேற்பரப்பிற்கு அருகே தேங்குகின்றன.
  • இதனால் வேளாண் உற்பத்தித்திறன் குறையலாம்.
57. பாசனத் திறன்
  • வழங்கப்பட்ட நீரில் பயிர்கள் பயனுள்ளதாகப் பயன்படுத்தும் பகுதியின் விகிதமே பாசனத் திறன்.
  • திறனை மேம்படுத்துவதால் தேவையற்ற நீர் எடுப்பை குறைக்கலாம்.
58. பல்நோக்கு ஆற்றுப்பள்ளத்தாக்குத் திட்டங்கள்
  • பல்நோக்கு திட்டங்கள் வழங்கக்கூடியவை:
  • பாசனம்.
  • நீர்மின்சாரம்.
  • வெள்ளக் கட்டுப்பாடு.
  • குடிநீர்.
  • தொழிற்சாலை நீர்.
  • நீர்வழிப் போக்குவரத்து.
  • மீன்வளம்.
  • பொழுதுபோக்கு.

59. அணை
  • ஆறு அல்லது பள்ளத்தாக்கின் குறுக்கே கட்டப்படும் தடுப்பே அணை.
  • இது நீரைச் சேமிக்கவோ கட்டுப்படுத்தவோ செய்கிறது.
  • அணையின் பின்னால் சேமிக்கப்படும் நீர் நீர்த்தேக்கத்தை உருவாக்குகிறது.
60. நீர்த்தேக்கம்
  • முக்கியமாக நீரைச் சேமிப்பதற்காக உருவாக்கப்பட்ட செயற்கை அல்லது விரிவுபடுத்தப்பட்ட நீர்நிலையே நீர்த்தேக்கம்.
  • இது அதிக பருவகால மாறுபாடு கொண்ட ஆற்றோட்டத்தை ஒழுங்குபடுத்த முடியும்.
61. அணைகளின் முக்கிய நன்மைகள்
  • நன்மைகள்:
  • பாசனம்.
  • மின்சாரம்.
  • நீர்வழங்கல்.
  • வெள்ளத் தணிப்பு.
  • வறட்சி நிவாரணம்.
  • மீன்வளம்.
62. பெரிய அணைகளுடன் தொடர்புடைய முக்கிய பிரச்சினைகள்
  • சாத்தியமான பிரச்சினைகள்:
  • மக்கள் இடம்பெயர்வு.
  • காடுகள் நீரில் மூழ்குதல்.
  • வாழிடம் இழப்பு.
  • வண்டல் தடுக்கப்படுதல்.
  • கீழ்நோக்கி ஆற்றோட்டத்தில் மாற்றம்.
  • மறுவாழ்வு தொடர்பான பிரச்சினைகள்.
  • மீன்களின் இடம்பெயர்வு முறை மாறுதல்.
63. நீர்த்தேக்கங்களில் வண்டல் படிதல்
  • ஆறுகள் வண்டலை நீர்த்தேக்கங்களுக்கு கொண்டு செல்கின்றன.
  • வண்டல் படிப்படியாக தேங்குகிறது.
  • இதனால் சேமிப்பு திறன் குறைகிறது.
  • நீர்ப்பிடிப்பு பகுதியில் ஏற்படும் அரிப்பு வண்டல் படிதலை வேகப்படுத்துகிறது.
64. நீர்ப்பிடிப்பு பகுதி
  • ஆறு, ஏரி அல்லது நீர்த்தேக்கத்திற்கு நீர் வடிகாலும் நிலப்பரப்பே நீர்ப்பிடிப்பு பகுதி அல்லது வடிநிலப் பகுதி.
  • நீர்ப்பிடிப்பு பகுதி மேலாண்மை நீரின் அளவையும் தரத்தையும் பாதிக்கிறது.
65. நீர்வடிப்பு பகுதி
  • ஒரே வெளியேற்ற இடத்திற்குத் தண்ணீர் வடிகாலும் நிலப்பரப்பே நீர்வடிப்பு பகுதி.
  • இந்திய வளர்ச்சி திட்டங்களில், நீர்வடிப்பு பகுதி என்பது மேலாண்மை அலகாகப் பயன்படுத்தப்படும் சிறிய வடிநிலப் பகுதியையும் குறிக்கிறது.
66. நீர்வடிப்பு பகுதி மேலாண்மை
  • நீர்வடிப்பு பகுதி மேலாண்மையின் நோக்கங்கள்:
  • மண் அரிப்பைக் குறைத்தல்.
  • ஊடுருவலை அதிகரித்தல்.
  • நிலத்தடி நீரை மீள்நிரப்புதல்.
  • மேற்பரப்பு ஓட்டத்தை மெதுவாக்குதல்.
  • தாவர மூடலை மேம்படுத்துதல்.
  • நீர் கிடைப்பை அதிகரித்தல்.
67. சமஉயரக் கட்டுப்படிகள்
  • சமஉயரக் கோடுகளுக்கு இணையாக மண் கட்டுப்படிகள் அமைக்கப்படுகின்றன.
  • இவை மேற்பரப்பு ஓட்டத்தை மெதுவாக்குகின்றன.
  • மண் அரிப்பைக் குறைக்கின்றன.
  • ஊடுருவலை அதிகரிக்கின்றன.
68. சிறிய தடுப்பணை
  • சிறிய தடுப்பணை என்பது ஓடை அல்லது வடிகால் பாதையின் குறுக்கே அமைக்கப்படும் சிறிய தடுப்பு.
  • இது மேற்பரப்பு ஓட்டத்தை மெதுவாக்குகிறது.
  • அதன் பின்னால் தற்காலிகமாக நீர் தேங்கும்.
  • நிலத்தடி நீர் மீள்நிரப்பு அதிகரிக்கலாம்.

69. ஊடுருவல் குளம்
  • ஊடுருவல் குளம், தாழ்வான பகுதியில் மேற்பரப்பு ஓட்டத்தைச் சேமிக்கிறது.
  • சேமிக்கப்பட்ட நீர் படிப்படியாக மண்ணுக்குள் ஊடுருவுகிறது.
  • இதன் முக்கிய நோக்கம் நிலத்தடி நீர் மீள்நிரப்பு.
70. மீள்நிரப்பு கிணறு
  • மீள்நிரப்பு கிணறுகள் மேற்பரப்பு நீரை ஆழமான நீர் ஊடுருவக்கூடிய அடுக்குகளுக்குள் செலுத்துகின்றன.
  • இயற்கை ஊடுருவல் குறைவான இடங்களில் இவை பயன்படுத்தப்படுகின்றன.
71. மழைநீர் சேகரிப்பு
  • மழைநீரைச் சேகரித்து வைத்தல் அல்லது நிலத்தடி நீர் மீள்நிரப்பிற்காக வழிமாற்றுதல் மழைநீர் சேகரிப்பு எனப்படுகிறது.
  • இது வெளிப்புற நீர்வழங்கல்களின் மீதான சார்பை குறைக்கிறது.
72. கூரைமழைநீர் சேகரிப்பு
  • வழக்கமான அமைப்பில் அடங்குபவை:
  • கூரை நீர்ப்பிடிப்பு பகுதி.
  • மழைநீர் கால்வாய்கள்.
  • கீழிறக்கும் குழாய்.
  • வடிகட்டி.
  • சேமிப்பு தொட்டி அல்லது மீள்நிரப்பு அமைப்பு.
73. மழைநீர் சேகரிப்பின் நன்மைகள்
  • உள்ளூர் நீர் கிடைப்பை அதிகரிக்கிறது.
  • நிலத்தடி நீரை மீள்நிரப்புகிறது.
  • மழைநீர் மேற்பரப்பு ஓட்டத்தை குறைக்கிறது.
  • நகர்ப்புற வெள்ளத்தை குறைக்கிறது.
  • வீட்டு நீர்வழங்கலை பூர்த்திசெய்கிறது.
74. தமிழ்நாடு மற்றும் மழைநீர் சேகரிப்பு
  • தமிழ்நாட்டில் மழை பருவகாலமாக இருப்பதாலும் நிலத்தடி நீரின் மீது அழுத்தம் அதிகமிருப்பதாலும் மழைநீர் சேகரிப்பு மிகவும் முக்கியமானது.
  • நகர்ப்புறம் மற்றும் கிராமப்புறம் இரண்டிலும் கூரைமழைநீர் மீள்நிரப்பு அமைப்புகள் பரவலாக ஊக்குவிக்கப்படுகின்றன.
75. இந்தியாவின் பாரம்பரிய நீர் சேகரிப்பு முறைகள்
  • உதாரணங்கள்:
  • ஜோஹாட்கள்.
  • டாங்காக்கள்.
  • காடின்கள்.
  • பாவோலிகள் / படிக்கிணறுகள்.
  • அஹார்கள் மற்றும் பைன்கள்.
  • ஏரிகள்.
  • குல்கள்.
76. ஜோஹாட்
  • ஜோஹாட்கள் ராஜஸ்தானில் பாரம்பரியமாகப் பயன்படுத்தப்படும் சிறிய மண் நீர் சேகரிப்பு அமைப்புகள்.
  • இவை மேற்பரப்பு ஓட்டத்தைச் சேகரித்து நிலத்தடி நீர் மீள்நிரப்பை மேம்படுத்துகின்றன.
🔗 TNPSC Key Link

ஜோஹாட் → ராஜஸ்தான்

77. டாங்கா
  • டாங்கா என்பது நிலத்தடியில் அல்லது மூடப்பட்ட வடிவில் அமைக்கப்படும் மழைநீர் சேமிப்பு அமைப்பு.
  • இது வறண்ட ராஜஸ்தானில் பாரம்பரியமாகப் பயன்படுத்தப்படுகிறது.
🔗 TNPSC Key Link

டாங்கா → ராஜஸ்தான் மழைநீர் சேமிப்பு

78. காடின்
  • காடின் என்பது ராஜஸ்தானின் பாரம்பரிய மேற்பரப்பு ஓட்ட நீர் சேகரிப்பு முறை.
  • மண் தடுப்பணையின் பின்னால் நீர் தடுக்கப்படுகிறது.
  • மண்ணில் தங்கியுள்ள ஈரப்பதம் பயிரிடுதலை ஆதரிக்கிறது.
79. பாவோலி / படிக்கிணறு
  • படிக்கிணறுகள் படிகள் மூலம் கீழிறங்கி அணுகக்கூடிய ஆழமான கிணறுகள்.
  • இவை வரலாற்றில் மேற்கு மற்றும் வட இந்தியாவில் முக்கியத்துவம் பெற்றிருந்தன.
  • நிலத்தடி நீரைச் சேமித்து பொதுமக்களுக்கு நீர் அணுகலை வழங்கின.
80. அஹார்–பைன் அமைப்பு
  • அஹார்–பைன் என்பது முக்கியமாக பீகாருடன் தொடர்புடைய பாரம்பரிய நீர் மேலாண்மை முறை.
  • அஹார்கள் நீர் சேமிப்பு அமைப்புகள்.
  • பைன்கள் நீரை எடுத்துச் செல்லும் கால்வாய்கள்.
🔗 TNPSC Key Link

அஹார்–பைன் → பீகார்

81. குல்
  • குல்கள் இமயமலைப் பகுதிகளில், குறிப்பாக ஹிமாச்சலப் பிரதேசத்தில் பயன்படுத்தப்படும் பாரம்பரிய நீர்க்கால்வாய்கள்.
  • இவை மலை ஓடைகளின் நீரை பாசனத்திற்காக வழிமாற்றுகின்றன.
82. ஏரி
  • ஏரிகள் தமிழ்நாட்டின் பாரம்பரிய பாசனக் குளங்கள்.
  • இவை பருவமழை மேற்பரப்பு ஓட்டத்தைச் சேமிக்கின்றன.
  • உள்ளூர் பாசனம் மற்றும் நிலத்தடி நீர் மீள்நிரப்புக்கு இவை மிகவும் முக்கியமானவை.
83. நகர்ப்புற நீர்வழங்கல்
  • நகர்ப்புற நீர் பொதுவாகப் பெறப்படும் மூலங்கள்:
  • நீர்த்தேக்கங்கள்.
  • ஆறுகள்.
  • நிலத்தடி நீர்.
  • ஏரிகள்.
  • நீண்ட தூரக் குழாய்கள்.
  • சில கடலோர நகரங்களில் உவர்நீக்குதல்.
84. சென்னை நீர்மூலங்கள் — புவியியல் இணைப்பு
  • சென்னை பின்வரும் பல்வேறு மூலங்களின் சேர்க்கையை சார்ந்துள்ளது:
  • நீர்த்தேக்கங்கள்.
  • நிலத்தடி நீர்.
  • ஆற்றுப்படுகைகள் இடையிலான நீர் மாற்றம்.
  • உவர்நீக்குதல்.
  • பருவமழை நிரப்பும் ஏரிகள் மற்றும் குளங்கள்.
85. உவர்நீக்குதல்
  • கடல்நீர் அல்லது உவர்நீரிலிருந்து கரைந்துள்ள உப்புகளை நீக்குவதே உவர்நீக்குதல்.
  • நீர்ப்பற்றாக்குறை உள்ள கடலோரப் பகுதிகளில் இது நன்னீரை வழங்குகிறது.
  • தலைகீழ் ஒஸ்மோசிஸ் பொதுவாகப் பயன்படுத்தப்படும் தொழில்நுட்பம்.
🔗 TNPSC Key Link

உவர்நீக்குதல் → கடல்நீரை நன்னீராக மாற்றுதல்

86. தலைகீழ் ஒஸ்மோசிஸ்
  • அரை ஊடுருவக்கூடிய படலத்தின் வழியாக நீரை அழுத்தத்தால் செலுத்தும் முறையே தலைகீழ் ஒஸ்மோசிஸ்.
  • இதன் மூலம் உப்புகள் மற்றும் பல அசுத்தங்கள் நீரிலிருந்து பிரிக்கப்படுகின்றன.
87. உவர்நீக்குதலின் வரம்புகள்
  • சவால்கள்:
  • அதிக ஆற்றல் பயன்பாடு.
  • அதிக செலவு.
  • அதிக உப்புள்ள கழிவுநீர் அகற்றல்.
  • கடல் சுற்றுச்சூழல் பாதிப்புகள்.
88. நீர் மாசுபாடு
  • தீங்கு விளைவிக்கும் பொருட்கள் நீரின் தரத்தைத் தாழ்த்தும்போது நீர் மாசுபாடு ஏற்படுகிறது.
  • முக்கிய மூலங்கள்:
  • கழிவுநீர்.
  • தொழிற்சாலை கழிவுநீர்.
  • வேளாண் மேற்பரப்பு ஓட்டம்.
  • திடக் கழிவு.
  • எண்ணெய்.
  • சுரங்கக் கழிவுகள்.
89. கழிவுநீர் மாசுபாடு
  • சுத்திகரிக்கப்படாத கழிவுநீர் கரிமப் பொருட்களையும் நோய்க்கிருமிகளையும் நீரில் சேர்க்கிறது.
  • சிதைவுச் செயல் கரைந்த ஆக்சிஜனை பயன்படுத்துகிறது.
  • நீர்வழி நோய்கள் பரவக்கூடும்.
90. தொழிற்சாலை நீர் மாசுபாடு
  • தொழிற்சாலைகள் வெளியிடக்கூடியவை:
  • கனிம கனஉலோகங்கள்.
  • அமிலங்கள்.
  • காரங்கள்.
  • சாயங்கள்.
  • கரிம வேதிப்பொருட்கள்.
  • சூடான நீர்.
  • வெளியேற்றுவதற்கு முன் சுத்திகரிப்பு அவசியம்.
91. வேளாண் மேற்பரப்பு ஓட்டம்
  • உரங்களும் பூச்சிக்கொல்லிகளும் ஆறுகள் மற்றும் ஏரிகளுக்குள் கழுவிச் செல்லலாம்.
  • நைட்ரஜன் மற்றும் பாஸ்பரஸ் யூட்ரோபிகேஷனை அதிகரிக்கின்றன.
  • பூச்சிக்கொல்லிகள் நீர்வாழ் உயிரினங்களை பாதிக்கலாம்.
92. யூட்ரோபிகேஷன்
  • நீரில் ஊட்டச்சத்துகள் அதிகரிப்பதே யூட்ரோபிகேஷன்.
  • அதிக நைட்ரஜன் மற்றும் பாஸ்பரஸ் பாசி வளர்ச்சியைத் தூண்டுகின்றன.
  • சிதைவுச் செயல் கரைந்த ஆக்சிஜனை குறைக்கலாம்.
📌 Must-Memorise

ஊட்டச்சத்துகள் ↑ → பாசி பெருக்கம் → ஆக்சிஜன் ↓

93. உயிரியல் ஆக்சிஜன் தேவை
  • BOD என்பதன் விரிவாக்கம் Biological Oxygen Demand.
  • உயிர்ச்சிதைவுக்குட்படும் கரிமப் பொருட்களை நுண்ணுயிரிகள் சிதைக்கத் தேவையான ஆக்சிஜன் அளவை இது குறிக்கிறது.
  • அதிக BOD பொதுவாக அதிக கரிம மாசுபாட்டைக் குறிக்கிறது.
📌 Must-Memorise

அதிக BOD → அதிக கரிம மாசுபாடு

94. கரைந்த ஆக்சிஜன்
  • கரைந்த ஆக்சிஜன் அல்லது DO என்பது நீரில் உள்ள ஆக்சிஜன்.
  • மீன்கள் மற்றும் பல நீர்வாழ் உயிரினங்களுக்கு இது அவசியம்.
  • கடுமையான கரிம மாசுபாடு DO அளவைக் குறைக்கலாம்.
⚠️ TNPSC Trap

சுத்தமான நீர் → பொதுவாக அதிக DO
கரிம மாசுபாடு → அதிக BOD, குறைந்த DO

95. வேதியியல் ஆக்சிஜன் தேவை
  • COD என்பது மாசுப்பொருட்களை வேதியியல் முறையில் ஆக்சிசனேற்றத் தேவையான ஆக்சிஜன் சமமான அளவை அளக்கிறது.
  • இது நீர் மாசுபாட்டின் மற்றொரு குறியீடு.
96. வெப்ப மாசுபாடு
  • சூடான நீரை வெளியேற்றுவது நீரின் வெப்பநிலையை உயர்த்துகிறது.
  • சூடான நீரில் கரைந்த ஆக்சிஜன் அளவு குறைவாக இருக்கும்.
  • நீரியல் சூழலியல் அமைப்புகள் பாதிக்கப்படலாம்.
97. நிலத்தடி நீர் மாசுபாடு
  • நிலத்தடி நீர் மாசுபாட்டை சரிசெய்வது கடினம்; காரணங்கள்:
  • நீர் நிலத்தடியில் மெதுவாக நகர்கிறது.
  • மாசுப்பொருட்கள் நீண்டகாலம் நிலைத்திருக்கலாம்.
  • அக்விஃபரை சுத்தம் செய்வது செலவானது.
98. ஆற்று நீர் மாசுபாடு
  • முக்கிய காரணங்கள்:
  • நகர்ப்புற கழிவுநீர்.
  • தொழிற்சாலை கழிவுநீர் வெளியேற்றம்.
  • மத மற்றும் வீட்டு கழிவுகள்.
  • வேளாண் மேற்பரப்பு ஓட்டம்.
  • திடக் கழிவு கொட்டுதல்.
99. நீர்வளங்களாக ஈரநிலங்கள்
  • ஈரநிலங்கள்:
  • நீரைச் சேமிக்கின்றன.
  • வெள்ளத்தை குறைக்கின்றன.
  • நிலத்தடி நீரை மீள்நிரப்புகின்றன.
  • மாசுப்பொருட்களை வடிகட்டுகின்றன.
  • உயிர்ப்பல்வகைமையை ஆதரிக்கின்றன.
100. வெள்ளச்சமவெளி ஈரநிலங்கள்
  • வெள்ளச்சமவெளி ஈரநிலங்கள் அதிகப்படியான ஆற்றுநீரைச் சேமிக்கின்றன.
  • கீழ்நோக்கி ஏற்படும் வெள்ள உச்சத்தை குறைக்க உதவுகின்றன.
  • ஆக்கிரமிப்பு இந்த இயற்கை நீர் சேமிப்பு செயல்பாட்டைக் குறைக்கிறது.
101. ஏரிகள்
  • ஏரிகள் பின்வருமாறு இருக்கலாம்:
  • நன்னீர்.
  • உப்புநீர்.
  • இயற்கை.
  • செயற்கை.
  • டெக்டானிக்.
  • பனிப்பாறை சார்ந்த.
  • லகூன் வகை.
102. முக்கிய நன்னீர் ஏரிகள்
  • உதாரணங்கள்:
  • வுலர்.
  • லோக்டக்.
  • கொல்லேரு.
  • வெவ்வேறு ஏரிகளுக்கு வெவ்வேறு புவியியல் தோற்றங்கள் உள்ளன.
103. வுலர் ஏரி
  • வுலர் ஏரி ஜம்மு மற்றும் காஷ்மீரில் உள்ளது.
  • இது முக்கியமான நன்னீர் ஏரி.
  • இது ஜீலம் ஆற்று அமைப்புடன் தொடர்புடையது.
🔗 TNPSC Key Link

வுலர் → ஜம்மு & காஷ்மீர்

104. லோக்டக் ஏரி
  • லோக்டக் ஏரி மணிப்பூரில் உள்ளது.
  • ‘பும்டிஸ்’ எனப்படும் மிதக்கும் தாவர மற்றும் கரிமப் பொருள் திரள்களுக்கு இது புகழ்பெற்றது.
  • கெய்புல் லாம்ஜாவோ தேசியப் பூங்கா மிதக்கும் பும்டி அமைப்புகளின் மீது அமைந்துள்ளது.
📌 Must-Memorise

லோக்டக் → மணிப்பூர் → பும்டிஸ்

105. கொல்லேரு ஏரி
  • கொல்லேரு ஆந்திரப் பிரதேசத்தில் உள்ளது.
  • இது கிருஷ்ணா மற்றும் கோதாவரி டெல்டா பகுதிகளுக்கிடையில் அமைந்த நன்னீர் ஏரி.
106. உப்புநீர் மற்றும் உவர்நீர் ஏரிகள்
  • உதாரணங்கள்:
  • சாம்பர் → உள்நாட்டு உப்புநீர் ஏரி.
  • சிலிகா → உவர்நீர் லகூன்.
  • புலிகாட் → உவர்நீர் லகூன்.
107. நீர்த்தேக்கங்கள்
  • பெரிய அணைகளுடன் தொடர்புடைய முக்கிய நீர்த்தேக்கங்கள் காணப்படும் பகுதிகள்:
  • இமயமலை ஆறுகள்.
  • தீபகற்ப ஆறுகள்.
  • மத்திய இந்திய ஆறுகள்.
  • ஒவ்வொரு திட்டத்திற்குமான விரிவான தகவல்கள் ஆறு தொடர்பான அத்தியாயங்களில் சேர்க்கப்படும்.
108. ஆற்றுப்படுகைகள் இடையிலான நீர் மாற்றம்
  • ஒரு ஆற்றுப்படுகையிலிருந்து மற்றொரு ஆற்றுப்படுகைக்கு நீரை மாற்றுவதே ஆற்றுப்படுகைகள் இடையிலான நீர் மாற்றம்.
  • நீர் கிடைப்பில் உள்ள பிராந்திய சமமற்ற தன்மையைச் சமாளிப்பதே இதன் நோக்கம்.
  • இத்தகைய திட்டங்களில் குறிப்பிடத்தக்க பொறியியல், சூழலியல் மற்றும் சமூக அம்சங்கள் உள்ளன.
109. ஆறுகளை இணைத்தல் — கருத்து
  • தேர்ந்தெடுக்கப்பட்ட ஆற்றுப்படுகைகளை கால்வாய்கள் மற்றும் நீர்த்தேக்கங்கள் மூலம் இணைப்பதே ஆறுகளை இணைக்கும் திட்டத்தின் முன்மொழிவு.
  • நோக்கங்களில் அடங்குபவை:
  • பாசனம்.
  • நீர் மாற்றம்.
  • வெள்ளத் தணிப்பு.
  • வறட்சி நிவாரணம்.
  • சாத்தியமான சூழலியல் மற்றும் இடம்பெயர்வு பாதிப்புகளை கவனமாக மதிப்பிட வேண்டும்.
110. நீர் பாதுகாப்பு
  • முக்கிய பாதுகாப்பு முறைகள்:
  • மழைநீர் சேகரிப்பு.
  • நீர்வடிப்பு பகுதி மேலாண்மை.
  • திறமையான பாசனம்.
  • குள மறுசீரமைப்பு.
  • நிலத்தடி நீர் மீள்நிரப்பு.
  • சுத்திகரிக்கப்பட்ட கழிவுநீரை மறுபயன்பாடு.
  • கசிவை குறைத்தல்.
111. தேவைப்புற மேலாண்மை
  • நீர் பாதுகாப்பு என்பது வழங்கலை அதிகரிப்பது மட்டுமல்ல.
  • தேவையை பின்வருமாறு குறைக்கலாம்:
  • திறமையான பாசனம்.
  • குறைந்த நீர் தேவைப்படும் பயிர்கள்.
  • மறுபயன்பாடு.
  • மீட்டர் முறை.
  • கசிவு கட்டுப்பாடு.
  • நீர் சேமிக்கும் வீட்டு உபகரணங்கள்.
112. கழிவுநீர் மறுபயன்பாடு
  • சுத்திகரிக்கப்பட்ட கழிவுநீரை பின்வற்றிற்குப் பயன்படுத்தலாம்:
  • தொழில்.
  • பசுமைப்பரப்பு பராமரிப்பு.
  • பொருத்தமான சூழலில் வேளாண்மை.
  • குடிநீரல்லாத நகர்ப்புற பயன்பாடுகள்.
  • மறுபயன்பாடு நன்னீரின் மீதான தேவையை குறைக்கிறது.
113. சாம்பல் நீர்
  • குளியல், கழுவும் தொட்டி மற்றும் துணி துவைப்பிலிருந்து வரும் ஒப்பீட்டளவில் குறைவாக மாசுபட்ட வீட்டு கழிவுநீரே சாம்பல் நீர்.
  • தகுந்த சுத்திகரிப்புக்குப் பிறகு சில குடிநீரல்லாத பயன்பாடுகளுக்கு இதை மீண்டும் பயன்படுத்தலாம்.
114. கருநீர்
  • கருநீரில் கழிப்பறை கழிவுகள் அடங்கும்.
  • நோய்க்கிருமிகள் மற்றும் அதிக கரிமச் சுமை காரணமாக இதற்கு தீவிரமான சுத்திகரிப்பு தேவை.
115. நீர் தடம்
  • ஒரு பொருள் அல்லது சேவையை உற்பத்தி செய்ய நேரடியாகவும் மறைமுகமாகவும் பயன்படுத்தப்படும் நன்னீரை நீர் தடம் குறிக்கிறது.
  • உணவுப் பொருட்களுக்கு பெரிய மறைமுக நீர் தேவைகள் இருக்கலாம்.
116. மெய்நிகர் நீர்
  • ஒரு பொருளின் உற்பத்தியில் மறைந்திருக்கும் நீரே மெய்நிகர் நீர்.
  • அதிக நீர் தேவைப்படும் பொருள் வர்த்தகம் செய்யப்படும் போது, மெய்நிகர் நீரும் பிராந்தியங்களுக்கு இடையே மாற்றப்படுவதாகக் கருதப்படுகிறது.
📌 TNPSC Advanced Fact

மெய்நிகர் நீர் → உற்பத்தியில் மறைந்திருக்கும் நீர் பயன்பாடு

117. அதிக நீர் தேவைப்படும் பயிர்கள்
  • உதாரணங்கள்:
  • நெல்.
  • கரும்பு.
  • இவற்றின் தாக்கம் உள்ளூர் காலநிலை, பாசனத் திறன் மற்றும் நீர் கிடைப்பை சார்ந்துள்ளது.
118. பயிர் தேர்வு மற்றும் நீர் பாதுகாப்பு
  • உள்ளூர் மழை மற்றும் நீர் கிடைப்புக்கு ஏற்ற பயிர்களைத் தேர்வு செய்வது பாசன அழுத்தத்தை குறைக்கலாம்.
  • நெல் அல்லது கரும்புடன் ஒப்பிடும்போது சிறுதானியங்களுக்கு பொதுவாகக் குறைந்த நீர் தேவை.
119. வறட்சித் தடுப்பு நடவடிக்கைகள்
  • நடவடிக்கைகள்:
  • நீர்வடிப்பு பகுதி மேம்பாடு.
  • பண்ணைக் குளங்கள்.
  • குள மறுசீரமைப்பு.
  • வறட்சியைத் தாங்கும் பயிர்கள்.
  • நுண்ணீர்ப்பாசனம்.
  • நிலத்தடி நீர் மீள்நிரப்பு.
120. பண்ணைக் குளம்
  • பண்ணைக் குளம் என்பது வேளாண் நிலத்தில் அமைக்கப்படும் சிறிய நீர் சேமிப்பு அமைப்பு.
  • இது துணைப் பாசனத்திற்காக மேற்பரப்பு ஓட்டத்தைச் சேகரிக்கிறது.
121. சிறிய தடுப்பணை vs பெரிய அணை
  • சிறிய தடுப்பணை:
  • சிறியது.
  • உள்ளூர் அளவிலானது.
  • முக்கியமாக மேற்பரப்பு ஓட்டத்தை மெதுவாக்கி மீள்நிரப்பை மேம்படுத்துகிறது.
  • பெரிய அணை:
  • பெரிய அளவு சேமிப்பு.
  • பல்நோக்கு பயன்பாடுகள்.
  • பெரிய சுற்றுச்சூழல் மற்றும் சமூக தாக்கங்கள்.
122. நீர்வடிப்பு பகுதி vs ஆற்றுப்படுகை
  • ஒரு ஆறும் அதன் துணை ஆறுகளும் வடிகாலும் முழு நிலப்பரப்பே ஆற்றுப்படுகை.
  • பெரிய ஆற்றுப்படுகைக்குள் உள்ள சிறிய வடிநில அலகை நீர்வடிப்பு பகுதி என்று குறிப்பிடலாம்.
  • இரண்டிற்கும் எல்லையாக நீர்ப்பிரிப்பு உயர்நிலங்கள் அமைகின்றன.
123. நீர்ப்பிரிப்பு
  • அருகருகே உள்ள வடிநிலப் பகுதிகளைப் பிரிக்கும் உயர்ந்த நிலப்பகுதியே நீர்ப்பிரிப்பு.
  • இதன் இருபுறங்களிலும் விழும் நீர் வெவ்வேறு ஆற்று அமைப்புகளுக்கு பாய்கிறது.
124. நிரந்தர ஆறு
  • ஆண்டு முழுவதும் நீர் பாயும் ஆறு நிரந்தர ஆறு.
  • மழையுடன் பனி மற்றும் பனிப்பாறை உருகுநீரையும் பெறுவதால் இமயமலை ஆறுகள் பொதுவாக நிரந்தர ஆறுகள்.
125. பருவகால ஆறு
  • மழைக்காலத்தில் பருவகால ஆறுகளில் நீர்ப்பாய்ச்சி மிகவும் அதிகரிக்கும்.
  • பல தீபகற்ப ஆறுகள் இமயமலை ஆறுகளை விட அதிக பருவகால மாறுபாட்டைக் காட்டுகின்றன.
126. அடியோட்டம்
  • நிலத்தடி நீர் ஆற்றோட்டத்திற்கு வழங்கும் பங்களிப்பே அடியோட்டம்.
  • அளவுக்கு மீறிய நிலத்தடி நீர் எடுப்பு வறண்ட காலங்களில் ஆற்றோட்டத்தை குறைக்கலாம்.
127. மேற்பரப்பு ஓட்டம்
  • நிலத்தின் மேல் பாய்ந்து ஓடைகள் மற்றும் ஆறுகளுக்குச் செல்லும் நீரே மேற்பரப்பு ஓட்டம்.
  • தார்சாலைகள் மற்றும் கான்கிரீட் மேற்பரப்புகள் ஊடுருவலைக் குறைப்பதால் நகர்மயமாக்கல் விரைவான மேற்பரப்பு ஓட்டத்தை அதிகரிக்கிறது.
128. நகர்மயமாக்கல் மற்றும் நீர்சுழற்சி
  • நகர்மயமாக்கல் ஏற்படுத்தக்கூடியவை:
  • குறைந்த ஊடுருவல்.
  • அதிக மேற்பரப்பு ஓட்டம்.
  • அதிக வெள்ளம்.
  • குறைந்த நிலத்தடி நீர் மீள்நிரப்பு.
  • அதிகரித்த நீர் தேவை.
129. ஈரநில ஆக்கிரமிப்பு
  • ஈரநிலங்களை நிரப்புதல் அல்லது கட்டிடமிடுதல் இயற்கை நீர் சேமிப்பை குறைக்கிறது.
  • இது நகர்ப்புற வெள்ள அபாயத்தை அதிகரிக்கலாம்.
  • மேலும் நிலத்தடி நீர் மீள்நிரப்பையும் உயிர்ப்பல்வகைமையையும் குறைக்கிறது.
130. சென்னை — நீர் புவியியல்
  • முக்கிய புவியியல் பிரச்சினைகள்:
  • மழை சில பருவங்களில் அதிகமாகக் குவிவது.
  • வடகிழக்குப் பருவமழை மீது சார்பு.
  • கடலோர நிலத்தடி நீர் அழுத்தம்.
  • நகர்ப்புற ஏரி மற்றும் ஈரநில மேலாண்மை.
  • வெள்ளம்–வறட்சி சுழற்சிகள்.
131. தமிழ்நாடு மற்றும் பருவகால நீர்ப்பற்றாக்குறை
  • தமிழ்நாட்டுக்குள் முழுமையாக உருவாகும் பெரிய நிரந்தர ஆறுகள் குறைவாக உள்ளன.
  • மழைப்பொழிவு மிகவும் பருவகாலத்தை சார்ந்துள்ளது.
  • எனவே நீர்த்தேக்கங்கள், குளங்கள் மற்றும் நிலத்தடி நீர் மிகவும் முக்கியமானவை.
132. தமிழ்நாட்டின் ஆற்றுச் சார்பு
  • தமிழ்நாடு சார்ந்திருப்பவை:
  • காவிரி அமைப்பு.
  • தாமிரபரணி.
  • வைகை.
  • பாலாறு.
  • பெண்ணையாறு.
  • பல சிறிய ஆறுகள் மற்றும் குளங்கள்.
  • விரிவான ஆற்றுத் தகவல்கள் பின்னர் இடம்பெறும்.
133. தாமிரபரணி — நீர்வள இணைப்பு
  • தாமிரபரணி தென் தமிழ்நாட்டின் முக்கியமான ஆறு.
  • மேற்குத் தொடர்ச்சி மலைகளில் உள்ள அதன் நீர்ப்பிடிப்பு பகுதி கணிசமான மழையைப் பெறுவதால், பல பருவகால ஆறுகளுடன் ஒப்பிடும்போது இது நம்பகமானதாக உள்ளது.
134. காவிரி — நீர்வள இணைப்பு
  • காவிரி தமிழ்நாட்டின் மிக முக்கியமான ஆறுகளில் ஒன்று.
  • இது ஆதரிப்பவை:
  • பாசனம்.
  • குடிநீர்.
  • வேளாண்மை.
  • நீர்மின்சாரம்.
  • இதன் டெல்டா முக்கிய நெல் சாகுபடி பகுதியாகும்.
135. பாலாறு — நீர்வள இணைப்பு
  • பாலாறு மிகவும் பருவகாலத்தை சார்ந்த ஆறு.
  • அதன் ஆற்றுப்படுகையில் நிலத்தடி நீர் எடுப்பு உள்ளூர் நீர்வழங்கலுக்கு முக்கியமானது.
136. வைகை — நீர்வள இணைப்பு
  • வைகை தென் தமிழ்நாட்டில் பாசனம் மற்றும் நீர்வழங்கலை ஆதரிக்கிறது.
  • இது வைகை நீர்த்தேக்க அமைப்புடன் தொடர்புடையது.
137. தமிழ்நாட்டில் நீர் மற்றும் வேளாண்மை
  • முக்கிய பிரச்சினைகள்:
  • பருவமழை மீது சார்பு.
  • குளப் பாசனம்.
  • நிலத்தடி நீர் எடுப்பு.
  • டெல்டா பாசனம்.
  • வறட்சி அபாயம்.
  • கடலோரப் பகுதிகளில் உப்புத்தன்மை.
138. குள மறுசீரமைப்பு
  • குளங்களை மறுசீரமைப்பதால்:
  • சேமிப்பு திறன் அதிகரிக்கும்.
  • பாசனம் மேம்படும்.
  • கிணறுகள் மீள்நிரப்பப்படும்.
  • உள்ளூர் வெள்ளம் குறையும்.
  • ஈரநில உயிர்ப்பல்வகைமை ஆதரிக்கப்படும்.
139. வண்டல் அகற்றுதல்
  • குளங்கள், கால்வாய்கள் அல்லது நீர்த்தேக்கங்களில் தேங்கிய வண்டலை அகற்றுவதே வண்டல் அகற்றுதல்.
  • இதனால் சேமிப்பு திறனை மீட்டெடுக்கலாம்.
  • விரைவாக மீண்டும் வண்டல் தேங்குவதைத் தடுக்க நீர்ப்பிடிப்பு பகுதி அரிப்பையும் கட்டுப்படுத்த வேண்டும்.
140. ஆவியாதல் இழப்பு
  • திறந்த நீர்த்தேக்கங்களில் ஆவியாதலால் நீர் இழப்பு ஏற்படும்.
  • சூடான மற்றும் வறண்ட பகுதிகளில் ஆவியாதல் குறிப்பாக அதிகமாக இருக்கும்.
141. வேளாண்மையில் நீர் பாதுகாப்பு
  • முறைகள்:
  • சொட்டு நீர்ப்பாசனம்.
  • தெளிப்பான் பாசனம்.
  • மல்சிங்.
  • சரியான பாசன நேரம்.
  • லேசர் நில சமன்படுத்தல்.
  • வறட்சியைத் தாங்கும் பயிர்கள்.
  • மண் ஈரப்பதப் பாதுகாப்பு.
142. மல்சிங்
  • மல்ச் மண் மேற்பரப்பை மூடுகிறது.
  • இது ஆவியாதலைக் குறைக்கிறது.
  • களைகளின் வளர்ச்சியைத் தடுக்கிறது.
  • மண் ஈரப்பதத்தைப் பாதுகாக்க உதவுகிறது.
143. நீர் சேகரிப்பு மற்றும் வெள்ளக் கட்டுப்பாடு
  • மழைநீர் சேகரிப்பு மூலம்:
  • உள்ளூர் மேற்பரப்பு ஓட்டத்தைச் சேகரிக்கலாம்.
  • மழைநீர் வடிகால்களின் அழுத்தத்தை குறைக்கலாம்.
  • வெள்ள உச்சத்தைத் தாழ்த்தலாம்.
  • நிலத்தடி நீரை மீள்நிரப்பலாம்.
144. நீர் பாதுகாப்புத்தன்மை
  • மனித ஆரோக்கியம், வாழ்வாதாரம், பொருளாதார நடவடிக்கைகள் மற்றும் சூழலியல் அமைப்புகளுக்குத் தேவையான அளவிலும் ஏற்ற தரத்திலும் நீர் நம்பகமாகக் கிடைப்பதே நீர் பாதுகாப்புத்தன்மை.
  • மனித ஆரோக்கியம்.
  • வாழ்வாதாரம்.
  • பொருளாதார நடவடிக்கை.
  • சூழலியல் அமைப்புகள்.
145. நீர் அழுத்தம்
  • புதுப்பிக்கத்தக்க நீர் கிடைப்பை நீர் தேவை அணுகும்போதோ மீறும்போதோ, அல்லது தரக் குறைவு பயன்படுத்தக்கூடிய நீரை வரையறுக்கும் போதோ நீர் அழுத்தம் ஏற்படும்.
  • அதிக மக்கள்தொகை அடர்த்தியும் பாசனத் தேவையும் நீர் அழுத்தத்தை அதிகரிக்கலாம்.
146. நீர் பாதுகாப்பு முன்னுரிமை வரிசை
  • ஒரு நடைமுறை அணுகுமுறை:
  • வீணாக்கத்தை குறைத்தல்.
  • திறனை மேம்படுத்துதல்.
  • நீரை மறுபயன்படுத்துதல்.
  • உள்ளூர் நீர்மூலங்களை மீள்நிரப்புதல்.
  • தேவைப்படும் இடங்களில் மட்டுமே புதிய நீர்மூலங்களை உருவாக்குதல்.
147. முக்கிய நீர் தொடர்பான சொற்கள்
  • அக்விஃபர் → நிலத்தடி நீரைத் தாங்கும் அமைப்பு.
  • மீள்நிரப்பு → நிலத்தடி நீர் மீண்டும் நிரம்புதல்.
  • நீர்வடிப்பு பகுதி → வடிநில அலகு.
  • மேற்பரப்பு ஓட்டம் → நிலத்தின் மேல் பாயும் நீர்.
  • ஊடுருவல் → மண்ணுக்குள் நீர் நுழைதல்.
  • கீழ்ஊடுருவல் → கீழ்நோக்கி நீர் நகர்வு.
  • நீர்த்தேக்கம் → சேமிக்கப்பட்ட மேற்பரப்பு நீர்.
  • நீர்மட்டம் → செறிவூட்டப்பட்ட நிலத்தடி நீரின் மேல்பரப்பு.
148. TNPSC அதிக மதிப்பெண் தரும் இணைப்புகள்
  • அக்விஃபர் → நிலத்தடி நீர்.
  • நீர்மட்டம் → செறிவூட்டப்பட்ட மண்டலத்தின் மேல்புற எல்லை.
  • ஆர்டீசியன் → அடைக்கப்பட்ட அக்விஃபர்.
  • ஏரி → தமிழ்நாட்டு குளம்.
  • ஜோஹாட் → ராஜஸ்தான்.
  • டாங்கா → ராஜஸ்தான்.
  • காடின் → ராஜஸ்தான்.
  • அஹார்–பைன் → பீகார்.
  • குல் → ஹிமாச்சலப் பிரதேசம்.
  • சொட்டு நீர்ப்பாசனம் → வேர் மண்டலம்.
  • தெளிப்பு நீர்ப்பாசனம் → செயற்கை மழை.
  • சிறிய தடுப்பணை → மீள்நிரப்பு.
  • ஊடுருவல் குளம் → மீள்நிரப்பு.
  • BOD → கரிம மாசுபாடு.
  • DO → நீர்வாழ் உயிர்களுக்கு ஆக்சிஜன்.
  • யூட்ரோபிகேஷன் → ஊட்டச்சத்து அதிகரிப்பு.
  • லோக்டக் → பும்டிஸ்.
  • சாம்பர் → உப்புநீர்.
  • சிலிகா → உவர்நீர்.
  • கொல்லேரு → நன்னீர்.
  • உவர்நீக்குதல் → உப்பு நீக்கம்.
149. TNPSC Traps
  • புதுப்பிக்கத்தக்க நீர் என்றால் அளவற்ற நீர் என்று பொருள் அல்ல.
  • நிலத்தடி நீர் எல்லா இடங்களிலும் நிலத்தடி ஆறு போல இருப்பதில்லை.
  • அக்விஃபர் நிலத்தடி நீரைச் சேமித்து கடத்துகிறது.
  • நீர்மட்டம் நிலையானதல்ல; அது உயரும் மற்றும் குறையும்.
  • கடினப் பாறை பீடபூமிகளை விட வட இந்திய வண்டல் சமவெளிகளில் பொதுவாக நிலத்தடி நீர் சேமிப்பு அதிகம்.
  • அளவுக்கு மீறிய பம்பிங் கடலோரப் பகுதிகளில் கடல்நீர் ஊடுருவலை ஏற்படுத்தலாம்.
  • தீபகற்ப இந்தியாவில் குளப் பாசனம் மிகவும் முக்கியமானது.

  • கருநீர் என்றால் என்ன? → கழிப்பறை கழிவுகள் கொண்ட கழிவுநீர்.

  • கொல்லேரு ஏரி எங்கு உள்ளது? → ஆந்திரப் பிரதேசம்.

  • பெரிய அளவு நகர்ப்புற தார்சாலை/கான்கிரீட் பரப்புகளால் ஊடுருவலுக்கு என்ன ஆகும்? → குறையும்.
