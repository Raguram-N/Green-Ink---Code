1. அடிப்படைத் தகவல்கள்
  • மின்னணுவியல் என்பது சாதனங்கள் மற்றும் சுற்றுகளில் எலக்ட்ரான்கள் அல்லது பிற மின்சுமைத் தாங்கிகளின் கட்டுப்படுத்தப்பட்ட ஓட்டத்தைப் பற்றிய அறிவியல் மற்றும் பொறியியல் துறையாகும்.
  • நவீன மின்னணுவியல் பெரும்பாலும் குறைக்கடத்தி பொருட்களை அடிப்படையாகக் கொண்டது.
  • சிலிக்கான் மிகவும் பரவலாகப் பயன்படுத்தப்படும் குறைக்கடத்தி ஆகும்.
  • ஜெர்மேனியம் மற்றொரு முக்கிய குறைக்கடத்தி ஆகும்.
  • மின்னணு சாதனங்கள் பெருக்கம், சுவிட்சிங், கணக்கீடு, உணர்தல், தகவல் தொடர்பு மற்றும் கட்டுப்பாடு ஆகியவற்றிற்கு பயன்படுகின்றன.
  • பழைய வெற்றிடக் குழாய் சாதனங்களுடன் ஒப்பிடும்போது குறைக்கடத்தி சாதனங்கள் பொதுவாக சிறியவை, வேகமானவை மற்றும் அதிக ஆற்றல் திறன் கொண்டவை.
  • நவீன கணினிகள், ஸ்மார்ட்போன்கள், தொலைக்காட்சிகள் மற்றும் கட்டுப்பாட்டு அமைப்புகள் ஒருங்கிணைந்த மின்னணு சுற்றுகளைச் சார்ந்துள்ளன.

மின்னணுவியல் → குறைக்கடத்தி சாதனங்கள் + மின்சிக்னல்களின் கட்டுப்பாடு

2. கடத்திகள்
  • கடத்திகள் மின்னோட்டத்தை எளிதாகப் பாய அனுமதிக்கின்றன.
  • உலோகங்கள் பொதுவாக நல்ல கடத்திகள்.
  • மின்கம்பிகளில் செம்பு பரவலாகப் பயன்படுத்தப்படுகிறது.
  • கடத்திகளில் அதிக எண்ணிக்கையிலான நகரும் மின்சுமைத் தாங்கிகள் உள்ளன.
  • அவற்றின் மின்தடை ஒப்பீட்டளவில் குறைவாகும்.
3. மின்காப்பான்கள்
  • மின்காப்பான்கள் மின்னோட்ட ஓட்டத்தை வலுவாகத் தடுக்கின்றன.
  • ரப்பர், கண்ணாடி, பிளாஸ்டிக் மற்றும் செராமிக் ஆகியவை பொதுவான மின்காப்பான்கள்.
  • சாதாரண நிலைகளில் மின்காப்பான்களில் சுதந்திரமாக நகரும் மின்சுமைத் தாங்கிகள் மிகக் குறைவு.
  • அவற்றின் மின்தடைத் தன்மை மிகவும் அதிகம்.
4. குறைக்கடத்திகள்
  • குறைக்கடத்திகளின் மின்கடத்துத்திறன், கடத்திகள் மற்றும் மின்காப்பான்களுக்கு இடைப்பட்டதாக இருக்கும்.
  • சிலிக்கான் மற்றும் ஜெர்மேனியம் தனிமக் குறைக்கடத்திகள் ஆகும்.
  • வெப்பநிலை, ஒளி, மின்புலம் மற்றும் மாசூட்டல் (Doping) மூலம் குறைக்கடத்தியின் கடத்துத்திறனை கட்டுப்படுத்தலாம்.
  • டைோடுகள், டிரான்சிஸ்டர்கள் மற்றும் ஒருங்கிணைந்த சுற்றுகளின் அடிப்படையாக குறைக்கடத்திகள் உள்ளன.
  • வெப்பநிலை அதிகரிக்கும்போது குறைக்கடத்தியின் மின்தடை பொதுவாகக் குறைகிறது.
🔗 TNPSC Key Link

சிலிக்கான் + ஜெர்மேனியம் → குறைக்கடத்திகள்

5. சிலிக்கான்
  • சிலிக்கானின் அணு எண் 14.
  • சிலிக்கானில் நான்கு இணைதிறன் எலக்ட்ரான்கள் உள்ளன.
  • இது குழு 14-ஐச் சேர்ந்த தனிமம்.
  • சிலிக்கான் தனது படிக வலையில் சகபிணைப்புகளை உருவாக்குகிறது.
  • ஒருங்கிணைந்த சுற்றுகளில் அதிகமாகப் பயன்படுத்தப்படும் முக்கிய குறைக்கடத்தி சிலிக்கான் ஆகும்.
  • பூமியின் மேற்புறத்தில் சிலிக்கா மற்றும் சிலிக்கேட்கள் போன்ற சேர்மங்களாக சிலிக்கான் அதிகளவில் காணப்படுகிறது.
🔗 TNPSC Key Link

சிலிக்கான் → 4 இணைதிறன் எலக்ட்ரான்கள் → முக்கிய IC குறைக்கடத்தி

6. ஜெர்மேனியம்
  • ஜெர்மேனியத்தின் அணு எண் 32.
  • இதில் நான்கு இணைதிறன் எலக்ட்ரான்கள் உள்ளன.
  • ஆரம்பகால குறைக்கடத்தி சாதனங்களில் ஜெர்மேனியம் முக்கியமாகப் பயன்படுத்தப்பட்டது.
  • சிலிக்கானை விட ஜெர்மேனியத்தின் ஆற்றல் இடைவெளி குறைவாகும்.
  • ஒத்த சிலிக்கான் சாதனங்களுடன் ஒப்பிடும்போது ஜெர்மேனியம் சாதனங்களில் கசிவு மின்னோட்டம் பொதுவாக அதிகமாக இருக்கும்.
7. ஆற்றல் பட்டைகள்

திண்மங்களில் காணப்படும் முக்கிய ஆற்றல் பகுதிகள்:

  • இணைதிறன் பட்டை.
  • கடத்தல் பட்டை.
  • தடைசெய்யப்பட்ட ஆற்றல் இடைவெளி.
  • இந்தப் பட்டைகளின் அமைப்பே ஒரு திண்மத்தின் மின்சார நடத்தையை நிர்ணயிக்கிறது.
8. இணைதிறன் பட்டை
  • இணைதிறன் பட்டையில் பிணைப்பில் ஈடுபடும் எலக்ட்ரான்கள் உள்ளன.
  • குறைக்கடத்திகளில், இணைதிறன் பட்டையிலிருந்து கடத்தல் பட்டைக்கு எலக்ட்ரான்கள் ஆற்றல் பெற்று நகர முடியும்.
  • இணைதிறன் பட்டையில் எலக்ட்ரான் விட்டுச் செல்லும் காலியிடம் ‘துளை’ (hole) போல் செயல்படுகிறது.
9. கடத்தல் பட்டை
  • கடத்தல் பட்டையில் உள்ள எலக்ட்ரான்கள் பொருளுக்குள் நகர்ந்து மின்னோட்டத்தை எடுத்துச் செல்ல முடியும்.
  • கடத்திகளில் நகரும் எலக்ட்ரான்கள் எளிதாகக் கிடைக்கின்றன.
  • குறைக்கடத்திகளில் போதுமான கடத்தல்-பட்டை எலக்ட்ரான்களை உருவாக்க பொதுவாக ஆற்றல் வழங்கப்பட வேண்டும்.
10. ஆற்றல் இடைவெளி
  • இணைதிறன் பட்டை மற்றும் கடத்தல் பட்டைக்கு இடையிலான ஆற்றல் வேறுபாடே ஆற்றல் இடைவெளி (Band gap) ஆகும்.
  • எளிமைப்படுத்திய மாதிரிகளில் கடத்திகளின் பட்டைகள் ஒன்றோடொன்று மேலெதிர்கொள்ளலாம் அல்லது தடைப்பட்ட இடைவெளி நடைமுறையில் இல்லாமல் இருக்கலாம்.
  • குறைக்கடத்திகளுக்கு சிறிய ஆற்றல் இடைவெளி உள்ளது.
  • மின்காப்பான்களுக்கு ஒப்பீட்டளவில் பெரிய ஆற்றல் இடைவெளி உள்ளது.
  • ஆற்றல் இடைவெளியின் அளவு ஒளியியல் மற்றும் மின்சார பண்புகளைப் பாதிக்கிறது.

11. உள்ளார்ந்த குறைக்கடத்தி
  • உள்ளார்ந்த குறைக்கடத்தி என்பது தூய குறைக்கடத்தி ஆகும்.
  • தூய சிலிக்கான் ஒரு உள்ளார்ந்த குறைக்கடத்தி.
  • தூய ஜெர்மேனியம் ஒரு உள்ளார்ந்த குறைக்கடத்தி.
  • வெப்ப ஆற்றல் எலக்ட்ரான்–துளை ஜோடிகளை உருவாக்குகிறது.
  • இலட்சிய உள்ளார்ந்த குறைக்கடத்தியில் எலக்ட்ரான்களின் எண்ணிக்கையும் துளைகளின் எண்ணிக்கையும் சமமாக இருக்கும்.
🔗 TNPSC Key Link

உள்ளார்ந்த → தூய குறைக்கடத்தி

12. எலக்ட்ரான்–துளை ஜோடி
  • இணைதிறன் எலக்ட்ரான் போதுமான ஆற்றலைப் பெற்றால் கடத்தல் பட்டைக்குச் செல்ல முடியும்.
  • அந்த எலக்ட்ரான் விட்டுச் செல்லும் காலியிடம் ‘துளை’ எனப்படும்.
  • எலக்ட்ரானும் துளையும் சேர்ந்து எலக்ட்ரான்–துளை ஜோடியை உருவாக்குகின்றன.
  • குறைக்கடத்திகளில் எலக்ட்ரான்களும் துளைகளும் இரண்டும் மின்னோட்டத்திற்கு பங்களிக்கின்றன.
13. துளை
  • துளை என்பது இணைதிறன் பட்டை நிலையில் எலக்ட்ரான் இல்லாத காலியிடம்.
  • இது செயல்பாட்டு நேர்ம மின்சுமைத் தாங்கியாக நடக்கிறது.
  • துளைகள் தனித்த அடிப்படைத் துகள்கள் அல்ல.
  • துளையின் இயக்கம் என்பது இணைதிறன் எலக்ட்ரான்களின் தொடர் இடமாற்றத்தை குறிக்கிறது.
⚠️ TNPSC Trap

துளை → செயல்பாட்டு நேர்ம மின்சுமைத் தாங்கி; புரோட்டான் அல்ல.

14. மாசூட்டல் (Doping)
  • தூய குறைக்கடத்தியில் கட்டுப்படுத்தப்பட்ட அளவு அசுத்தங்களை திட்டமிட்டு சேர்ப்பதே மாசூட்டல் (Doping) ஆகும்.
  • மாசூட்டல் குறைக்கடத்தியின் கடத்துத்திறனை அதிகரித்து கட்டுப்படுத்துகிறது.
  • மாசூட்டப்பட்ட குறைக்கடத்தி புறச்சேர்க்கை குறைக்கடத்தி (Extrinsic semiconductor) எனப்படும்.
  • மாசூட்டலால் n-வகை அல்லது p-வகை குறைக்கடத்தி உருவாகிறது.
🔗 TNPSC Key Link

மாசூட்டல் → புறச்சேர்க்கை குறைக்கடத்தி

15. புறச்சேர்க்கை குறைக்கடத்தி

இதன் இரண்டு முக்கிய வகைகள்:

  • n-வகை குறைக்கடத்தி.
  • p-வகை குறைக்கடத்தி.
  • பெரும்பான்மை மின்சுமைத் தாங்கியின் வகை, சேர்க்கப்படும் மாசுப் பொருளைப் பொறுத்தது.
16. n-வகை குறைக்கடத்தி
  • சிலிக்கான் அல்லது ஜெர்மேனியத்தில் ஐவிணைதிறன் அசுத்தத்தைச் சேர்ப்பதன் மூலம் n-வகை குறைக்கடத்தி உருவாகிறது.
  • ஐவிணைதிறன் மாசூட்டிகளில் ஐந்து இணைதிறன் எலக்ட்ரான்கள் உள்ளன.
  • ஒரு கூடுதல் எலக்ட்ரான் கடத்தலுக்கு எளிதாகக் கிடைக்கிறது.
  • எலக்ட்ரான்கள் பெரும்பான்மை மின்சுமைத் தாங்கிகள்.
  • துளைகள் சிறுபான்மை மின்சுமைத் தாங்கிகள்.
  • n-வகை பொருள் மொத்தத்தில் மின்சார ரீதியாக நடுநிலையாகவே இருக்கும்.

17. ஐவிணைதிறன் மாசூட்டிகள்

பொதுவான தானம் செய்பவை:

  • பாஸ்பரஸ்.
  • ஆர்சனிக்.
  • ஆண்டிமனி.
  • இவைகளில் ஐந்து இணைதிறன் எலக்ட்ரான்கள் உள்ளன.
  • இவை கூடுதல் எலக்ட்ரான்களை வழங்குகின்றன.
  • எனவே இவை தானம் செய்பவை (Donor impurities) எனப்படுகின்றன.
📌 Remember

n-வகை → Donor → P, As, Sb

18. p-வகை குறைக்கடத்தி
  • மூவிணைதிறன் அசுத்தத்தைச் சேர்ப்பதன் மூலம் p-வகை குறைக்கடத்தி உருவாகிறது.
  • மூவிணைதிறன் மாசூட்டிகளில் மூன்று இணைதிறன் எலக்ட்ரான்கள் உள்ளன.
  • இவை படிக வலையில் துளைகளை உருவாக்குகின்றன.
  • துளைகள் பெரும்பான்மை மின்சுமைத் தாங்கிகள்.
  • எலக்ட்ரான்கள் சிறுபான்மை மின்சுமைத் தாங்கிகள்.
  • p-வகை குறைக்கடத்தியும் மொத்தத்தில் மின்சார ரீதியாக நடுநிலையாகவே இருக்கும்.
🔗 TNPSC Key Link

19. மூவிணைதிறன் மாசூட்டிகள்

பொதுவான ஏற்றுக்கொள்ளி அசுத்தங்கள்:

  • போரான்.
  • அலுமினியம்.
  • கேலியம்.
  • இண்டியம்.
  • இவை துளைகளை உருவாக்குகின்றன.
  • எனவே இவை ஏற்றுக்கொள்ளிகள் (Acceptor impurities) எனப்படுகின்றன.
📌 Remember

p-வகை → Acceptor → B, Al, Ga, In

20. பெரும்பான்மை மற்றும் சிறுபான்மை மின்சுமைத் தாங்கிகள்
  • n-வகை பெரும்பான்மை தாங்கிகள் → எலக்ட்ரான்கள்.
  • n-வகை சிறுபான்மை தாங்கிகள் → துளைகள்.
  • p-வகை பெரும்பான்மை தாங்கிகள் → துளைகள்.
  • p-வகை சிறுபான்மை தாங்கிகள் → எலக்ட்ரான்கள்.
⚠️ TNPSC Trap

n-வகை மொத்தத்தில் எதிர்ம மின்சுமை கொண்டதல்ல.

p-வகை மொத்தத்தில் நேர்ம மின்சுமை கொண்டதல்ல.

இரண்டும் மின்சார ரீதியாக நடுநிலையாகவே உள்ளன.

21. p–n சந்திப்பு
  • p-வகை மற்றும் n-வகை குறைக்கடத்தி பகுதிகளை இணைத்தால் p–n சந்திப்பு உருவாகிறது.
  • எலக்ட்ரான்கள் n-பக்கத்திலிருந்து p-பக்கத்துக்கு பரவுகின்றன.
  • துளைகள் p-பக்கத்திலிருந்து n-பக்கத்துக்கு பரவுகின்றன.
  • சந்திப்பு அருகே மறுசேர்க்கை நிகழ்கிறது.
  • இதனால் தேய்வு பகுதி (Depletion region) உருவாகிறது.
🔗 TNPSC Key Link

p + n → சந்திப்பு → தேய்வு பகுதி

22. தேய்வு பகுதி
  • தேய்வு பகுதியில் நகரும் மின்சுமைத் தாங்கிகள் மிகக் குறைவாக உள்ளன.
  • அதில் நிலைத்த அயனாக்கப்பட்ட donor மற்றும் acceptor அணுக்கள் உள்ளன.
  • உள் மின்புலம் உருவாகிறது.
  • இதனால் தடுப்பு மின்னழுத்தம் உருவாகிறது.
  • இந்தத் தடுப்பு, பெரும்பான்மை தாங்கிகள் மேலும் பரவுவதை எதிர்க்கிறது.
23. தடுப்பு மின்னழுத்தம்
  • p–n சந்திப்பின் குறுக்கே தடுப்பு மின்னழுத்தம் உருவாகிறது.
  • இது குறைக்கடத்தி பொருள் மற்றும் வெப்பநிலையைப் பொறுத்தது.
  • அடிப்படை மின்னணுவியலில் அறை வெப்பநிலையில் பொதுவாகப் பயன்படுத்தப்படும் மதிப்புகள்: சிலிக்கானுக்கு சுமார் 0.7 V, ஜெர்மேனியத்திற்கு சுமார் 0.3 V.
  • இவை அணுகுமுறை நடைமுறை மதிப்புகள்; எல்லா சூழலுக்கும் பொருந்தும் மாறாத நிலையான மதிப்புகள் அல்ல.
🔗 TNPSC Key Link

ஜெர்மேனியம் சந்திப்பு → ~0.3 V

24. குறைக்கடத்தி டையோடு
  • டையோடு என்பது இரண்டு முனைகள் கொண்ட குறைக்கடத்தி சாதனம்.
  • அதன் அடிப்படை வடிவில் ஒரு p–n சந்திப்பு உள்ளது.
  • அதன் முனைகள் அனோடு மற்றும் கேத்தோடு எனப்படுகின்றன.
  • டையோடு மின்னோட்டத்தை ஒரு திசையில் எளிதாக அனுமதித்து, எதிர்திசையில் வலுவாகத் தடுக்கிறது.
  • டையோடுகள் திருத்துதல், பாதுகாப்பு மற்றும் சிக்னல் செயலாக்கம் ஆகியவற்றில் பயன்படுகின்றன.
🔗 TNPSC Key Link

டையோடு → ஒருதிசை மின்னோட்ட சாதனம்

25. முன்னோக்கு சார்பு
  • p-பக்கம் நேர்ம மின்னழுத்தத்துக்கும் n-பக்கம் எதிர்ம மின்னழுத்தத்துக்கும் இணைக்கப்படும் போது p–n சந்திப்பு முன்னோக்கு சார்பில் இருக்கும்.
  • முன்னோக்கு சார்பு தடுப்பு மின்னழுத்தத்தைக் குறைக்கிறது.
  • தேய்வு பகுதி குறுகுகிறது.
  • போதுமான முன்னோக்கு மின்னழுத்தம் கொடுக்கப்பட்ட பிறகு குறிப்பிடத்தக்க மின்னோட்டம் பாய முடியும்.
🔗 TNPSC Key Link

முன்னோக்கு சார்பு → P நேர்மைக்கு, N எதிர்மைக்கு

26. பின்னோக்கு சார்பு
  • p-பக்கம் எதிர்ம மின்னழுத்தத்துக்கும் n-பக்கம் நேர்ம மின்னழுத்தத்துக்கும் இணைக்கப்படும் போது p–n சந்திப்பு பின்னோக்கு சார்பில் இருக்கும்.
  • பின்னோக்கு சார்பு தடுப்பு மின்னழுத்தத்தை அதிகரிக்கிறது.
  • தேய்வு பகுதி அகலமாகிறது.
  • சாதாரண டையோடில் breakdown ஏற்படும் வரை மிகச் சிறிய பின்னோக்கு மின்னோட்டமே பாயும்.
🔗 TNPSC Key Link

பின்னோக்கு சார்பு → P எதிர்மைக்கு, N நேர்மைக்கு

27. டையோடின் பண்புக்கோடு
  • சந்திப்பு செயல்பாட்டு turn-on பகுதியை அடைந்த பிறகு முன்னோக்கு மின்னோட்டம் வேகமாக உயர்கிறது.
  • சாதாரண பின்னோக்கு சார்பில் பின்னோக்கு மின்னோட்டம் மிகவும் குறைவு.
  • போதுமான அளவு உயர்ந்த பின்னோக்கு மின்னழுத்தத்தில் breakdown ஏற்படலாம்.
  • அந்த நிலைக்கு வடிவமைக்கப்படாத சாதாரண டையோடு breakdown காரணமாக சேதமடையலாம்.
28. திருத்துதல்
  • மாறுதிசை மின்னோட்டத்தை ஒருதிசை மின்னோட்டமாக மாற்றுவது திருத்துதல் (Rectification) ஆகும்.
  • குறைக்கடத்தி டையோடுகள் திருத்திகளாக பரவலாகப் பயன்படுத்தப்படுகின்றன.
  • மின்வழங்கிகளில் திருத்திகள் பயன்படுத்தப்படுகின்றன.
  • மென்மையான DC பெற, திருத்தியின் வெளியீடு பொதுவாக வடிகட்டப்பட வேண்டும்.
🔗 TNPSC Key Link

திருத்தி → AC முதல் DC

29. அரைஅலை திருத்தி
  • எளிய அரைஅலை திருத்தியில் ஒரு டையோடு பயன்படுத்தப்படுகிறது.
  • AC-யின் ஒரு அரைச்சுழற்சி மட்டும் load-ஐ அடைய அனுமதிக்கப்படுகிறது.
  • மற்ற அரைச்சுழற்சி தடுக்கப்படுகிறது.
  • வெளியீடு துடிப்பான DC ஆக இருக்கும்.
  • இதில் ஒப்பீட்டளவில் அதிக ripple உள்ளது.
30. முழுஅலை திருத்தி
  • முழுஅலை திருத்தி AC அலைவடிவத்தின் இரு அரைச்சுழற்சிகளையும் பயன்படுத்துகிறது.
  • அரைஅலை திருத்தியைவிட அதிக சராசரி வெளியீட்டுடன் துடிப்பான DC-ஐ உருவாக்குகிறது.
  • இதன் ripple இடைவெளி குறைவாக இருப்பதால் வடிகட்ட எளிதாகும்.
  • இது இரண்டு டையோடுகளுடன் centre-tapped transformer அல்லது bridge அமைப்பைப் பயன்படுத்தலாம்.
31. பாலம் திருத்தி
  • பாலம் திருத்தியில் பொதுவாக நான்கு டையோடுகள் பயன்படுத்தப்படுகின்றன.
  • இது முழுஅலை திருத்துதலை வழங்குகிறது.
  • இதற்கு centre-tapped transformer அவசியமில்லை.
  • AC-யின் இரு அரைச்சுழற்சிகளிலும் load வழியாக மின்னோட்டம் ஒரே திசையில் பாயும்.
🔗 TNPSC Key Link

பாலம் திருத்தி → 4 டையோடுகள்

32. வடிகட்டி சுற்று
  • வடிகட்டி, திருத்தியின் துடிப்பான வெளியீட்டை மென்மையாக்குகிறது.
  • கெபாசிட்டர்கள் பொதுவாக வடிகட்டிகளாகப் பயன்படுத்தப்படுகின்றன.
  • மின்னழுத்த உச்சங்களுக்கு அருகில் கெபாசிட்டர் மின்னேற்றம் பெறுகிறது.
  • உச்சங்களுக்கு இடையில் அது மின்னிறக்கம் செய்கிறது.
  • இதனால் வெளியீட்டு மின்னழுத்தத்தில் ripple குறைகிறது.
🔗 TNPSC Key Link

திருத்தி + வடிகட்டி → மென்மையான DC

33. ரிப்பிள்
  • திருத்தப்பட்ட DC வெளியீட்டில் மீதமிருக்கும் தேவையற்ற AC மாறுபாடு ripple எனப்படும்.
  • ஒத்த வடிகட்டல் நிலைகளில், முழுஅலை திருத்தியில் அரைஅலை திருத்தியைவிட பொதுவாக ripple குறைவாக இருக்கும்.
  • வடிகட்டி சுற்றுகள் ripple-ஐக் குறைக்கின்றன.
34. ஜீனர் டையோடு
  • ஜீனர் டையோடு பின்னோக்கு breakdown பகுதியில் பாதுகாப்பாக இயங்குமாறு வடிவமைக்கப்பட்டுள்ளது.
  • பயனுள்ள ஒரு மின்னோட்ட வரம்பில் சுமார் நிலையான மின்னழுத்தத்தைத் தக்கவைக்க முடியும்.
  • மின்னழுத்த ஒழுங்குபடுத்தல் மற்றும் reference voltage-க்கு ஜீனர் டையோடுகள் பரவலாகப் பயன்படுத்தப்படுகின்றன.
  • ஒழுங்குபடுத்தும் செயல்பாட்டில் அவை பொதுவாக பின்னோக்கு சார்பில் இயக்கப்படுகின்றன.

35. ஒளி உமிழும் டையோடு
  • LED என்பதன் விரிவாக்கம் Light-Emitting Diode.
  • LED முன்னோக்கு சார்பில் இயங்கும் போது ஒளி உமிழ்கிறது.
  • எலக்ட்ரான்–துளை மறுசேர்க்கையில் ஆற்றல் ஃபோட்டான்களாக வெளிவிடப்படுகிறது.
  • LED-கள் அதிக ஆற்றல் திறன் கொண்டவை.
  • அவற்றின் செயல்பாட்டு ஆயுள் நீண்டது.
  • காட்சிப்பலகைகள், குறியீட்டு விளக்குகள் மற்றும் ஒளியூட்டலில் LED-கள் பயன்படுகின்றன.

36. LED நிறங்கள்
  • LED-யின் நிறம் முக்கியமாக குறைக்கடத்தியின் band gap-ஐப் பொறுத்தது.
  • வேறு வேறு குறைக்கடத்தி பொருட்கள் வேறு வேறு அலைநீளங்களை உருவாக்குகின்றன.
  • சிவப்பு LED-களின் ஃபோட்டான் ஆற்றல் பொதுவாக நீல LED-களைவிடக் குறைவு.
  • நீல ஃபோட்டான்களின் ஆற்றல் சிவப்பு ஃபோட்டான்களை விட அதிகம்.
37. வெள்ளை LED
  • வெள்ளை LED-கள் பொதுவாக நீல அல்லது புறஊதா LED-யுடன் phosphor பொருட்களைப் பயன்படுத்துகின்றன.
  • phosphor, வெளிவரும் ஒளியின் ஒரு பகுதியை மற்ற அலைநீளங்களாக மாற்றுகிறது.
  • இணைந்த பல அலைநீளங்கள் மனிதக் கண்ணுக்கு வெள்ளை ஒளியாகத் தோன்றுகின்றன.
38. LED மற்றும் மின்வெப்ப விளக்கு
  • LED-கள் மின்சார ஆற்றலின் அதிகமான பகுதியை காட்சியளிக்கும் ஒளியாக மாற்றுகின்றன.
  • மின்வெப்ப விளக்குகள் மிக அதிக வெப்பத்தை உற்பத்தி செய்கின்றன.
  • LED-களின் ஆயுள் அதிகம்.
  • பல ஒளியூட்டல் சாதனங்களில் LED-களுக்கு குறைக்கடத்தி மின்னணு கட்டுப்பாடு தேவைப்படுகிறது.
39. போட்டோடையோடு
  • போட்டோடையோடு, படும் ஒளியை மின்னோட்டம் அல்லது மின்னழுத்தமாக மாற்றுகிறது.
  • இது பொதுவாக பின்னோக்கு சார்பில் இயக்கப்படுகிறது.
  • ஒளி எலக்ட்ரான்–துளை ஜோடிகளை உருவாக்குகிறது.
  • ஒளித் தகவல் தொடர்பு, உணரிகள் மற்றும் ஒளிக் கண்டறிவிகளில் போட்டோடையோடுகள் பயன்படுகின்றன.

40. சூரிய மின்கலம்
  • சூரிய மின்கலம் ஒளியை நேரடியாக மின்சார ஆற்றலாக மாற்றுகிறது.
  • இது photovoltaic effect மூலம் செயல்படுகிறது.
  • இது ஒரு குறைக்கடத்தி p–n சந்திப்பு சாதனம்.
  • சிலிக்கான் பரவலாகப் பயன்படுத்தப்படுகிறது.
  • சூரிய மின்கலங்கள் DC மின்சாரத்தை உற்பத்தி செய்கின்றன.

41. ஒளிமின்னழுத்த விளைவு
  • பொருத்தமான பொருளில் ஒளி உறிஞ்சப்படும் போது மின்னழுத்தமும் மின்னோட்டமும் உருவாகும் நிகழ்வே photovoltaic effect.
  • எலக்ட்ரான்–துளை ஜோடிகள் உருவாகின்றன.
  • உள்ளமைந்த மின்புலங்கள் மின்சுமைத் தாங்கிகளைப் பிரிக்கின்றன.
  • சூரிய மின்கலங்கள் இந்த விளைவைப் பயன்படுத்துகின்றன.
42. LDR
  • LDR என்பதன் விரிவாக்கம் Light Dependent Resistor.
  • இதன் மின்தடை ஒளித் தீவிரத்துடன் மாறுகிறது.
  • சாதாரண LDR-ல் ஒளித் தீவிரம் அதிகரிக்கும்போது மின்தடை குறைகிறது.
  • தானியங்கி தெருவிளக்குகள் மற்றும் ஒளி உணரிகளில் LDR-கள் பயன்படுகின்றன.

43. தெர்மிஸ்டர்
  • தெர்மிஸ்டர் என்பது வெப்பநிலைக்கு உணர்திறன் கொண்ட மின்தடை.
  • NTC தெர்மிஸ்டரில் வெப்பநிலை உயரும்போது மின்தடை குறைகிறது.
  • PTC தெர்மிஸ்டரில் வெப்பநிலை உயரும்போது மின்தடை அதிகரிக்கிறது.
  • வெப்பநிலை உணர்தல் மற்றும் பாதுகாப்புச் சுற்றுகளில் தெர்மிஸ்டர்கள் பயன்படுகின்றன.
44. டிரான்சிஸ்டர்
  • டிரான்சிஸ்டர் என்பது பெருக்கம் மற்றும் சுவிட்சிங் பயன்பாடுகளுக்கான குறைக்கடத்தி சாதனம்.
  • வெற்றிடக் குழாய்கள் பயன்படுத்தப்பட்ட பல இடங்களை மாற்றியதால் இது மின்னணு தொழில்நுட்பத்தில் புரட்சியை ஏற்படுத்தியது.
  • Bipolar Junction Transistor-ல் மூன்று குறைக்கடத்தி பகுதிகள் உள்ளன.
  • பொதுவான BJT வகைகள் NPN மற்றும் PNP.

45. டிரான்சிஸ்டர் கண்டுபிடிப்பு
  • முதல் வெற்றிகரமான point-contact transistor 1947-ல் செயல்படுத்திக் காட்டப்பட்டது.
  • John Bardeen மற்றும் Walter Brattain இதை Bell Laboratories-ல் உருவாக்கினர்.
  • William Shockley முக்கியமான transistor கோட்பாடு மற்றும் junction-transistor கருத்துகளை உருவாக்கினார்.
  • Bardeen, Brattain மற்றும் Shockley 1956 இயற்பியல் நோபல் பரிசைப் பகிர்ந்து கொண்டனர்.

46. Bipolar Junction Transistor
  • BJT என்பதன் விரிவாக்கம் Bipolar Junction Transistor.
  • இதில் இரண்டு p–n சந்திப்புகள் உள்ளன.
  • இதற்கு மூன்று முனைகள் உள்ளன.
  • அவை emitter, base மற்றும் collector.
  • இதன் இரண்டு அடிப்படை வகைகள் NPN மற்றும் PNP.
47. எமிட்டர்
  • எமிட்டர் அதிகமாக மாசூட்டப்பட்டுள்ளது.
  • இது பெரும்பான்மை மின்சுமைத் தாங்கிகளை வழங்குகிறது.
  • NPN டிரான்சிஸ்டரில் எமிட்டரிலிருந்து எலக்ட்ரான்கள் வழங்கப்படுகின்றன.
  • PNP டிரான்சிஸ்டரில் எமிட்டரிலிருந்து துளைகள் வழங்கப்படுகின்றன.
48. பேஸ்
  • பேஸ் பகுதி மிகவும் மெல்லியது.
  • எமிட்டருடன் ஒப்பிடும்போது இது குறைவாக மாசூட்டப்பட்டுள்ளது.
  • BJT-ல் சிறிய base current, அதைவிடப் பெரிய collector current-ஐ கட்டுப்படுத்த முடியும்.
  • மெல்லிய base காரணமாக செலுத்தப்பட்ட பெரும்பாலான தாங்கிகள் collector-ஐ அடைகின்றன.
49. கலெக்டர்
  • base பகுதி வழியாக வரும் மின்சுமைத் தாங்கிகளை collector சேகரிக்கிறது.
  • base-ஐ விட அதிக சக்தியைத் தாங்கும் வகையில் collector உடலமைப்பாக வடிவமைக்கப்படுகிறது.
  • பெருக்கி பயன்பாடுகளில் முக்கிய கட்டுப்படுத்தப்பட்ட மின்னோட்டம் collector current ஆகும்.
50. NPN டிரான்சிஸ்டர்
  • NPN டிரான்சிஸ்டர் n-p-n குறைக்கடத்தி பகுதிகளால் ஆனது.
  • எமிட்டரிலிருந்து செலுத்தப்படும் முக்கிய தாங்கிகள் எலக்ட்ரான்கள்.
  • சிறிய base current, பெரிய collector current-ஐ கட்டுப்படுத்துகிறது.
  • NPN டிரான்சிஸ்டர்கள் மின்னணு சுற்றுகளில் பரவலாகப் பயன்படுத்தப்படுகின்றன.
51. PNP டிரான்சிஸ்டர்
  • PNP டிரான்சிஸ்டர் p-n-p பகுதிகளால் ஆனது.
  • எமிட்டரிலிருந்து செலுத்தப்படும் முக்கிய தாங்கிகள் துளைகள்.
  • ஒத்த NPN சுற்றுடன் ஒப்பிடும்போது மரபு மின்னோட்ட திசைகள் எதிர்மாறாக இருக்கும்.
52. டிரான்சிஸ்டர் மின்னோட்ட உறவு

  • எமிட்டர் மின்னோட்டம் = கலெக்டர் மின்னோட்டம் + பேஸ் மின்னோட்டம்.
  • IE = IC + IB.

53. மின்னோட்டப் பெருக்கம்
  • Common-emitter current gain, β எனக் குறிக்கப்படுகிறது.
  • β = IC/IB.
  • ஆகவே சிறிய base current மூலம் பெரிய collector current-ஐ கட்டுப்படுத்த முடியும்.
  • β மதிப்பு டிரான்சிஸ்டர் மற்றும் செயல்பாட்டு நிலைகளின்படி மாறும்.
54. பெருக்கியாக டிரான்சிஸ்டர்
  • பெருக்கி ஒரு மின்சிக்னலின் வீச்சு அல்லது சக்தியை அதிகரிக்கிறது.
  • சிறிய உள்ளீட்டு மாற்றம் பெரிய வெளியீட்டு மாற்றத்தை கட்டுப்படுத்த முடியும்.
  • ஒலி, வானொலி மற்றும் உணரி பெருக்கிகளில் டிரான்சிஸ்டர்கள் பயன்படுத்தப்படுகின்றன.
  • பெருக்க செயலுக்கு வெளிப்புற ஆற்றல் மூலமொன்று தேவைப்படுகிறது.

55. சுவிட்சாக டிரான்சிஸ்டர்
