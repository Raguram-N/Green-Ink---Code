1. அடிப்படைத் தகவல்கள்
  • வடக்கு சமவெளிகள் இமயமலையின் உடனடி தெற்குப் பகுதியில் அமைந்துள்ளன.
  • அவை மேற்கில் பஞ்சாபிலிருந்து கிழக்கில் அசாம் வரை பரவியுள்ளன.
  • சிந்து, கங்கை மற்றும் பிரம்மபுத்திரா நதி அமைப்புகளின் படிவச் செயலால் இவை முக்கியமாக உருவானவை.
  • இவை பெரும்பாலும் வண்டல் படிவங்களால் ஆனவை.
  • இந்தியாவின் மிக வளமானதும் அதிக மக்கள் அடர்த்தி கொண்டதுமான பகுதிகளில் இவை ஒன்றாகும்.
  • சமமான நிலப்பரப்பு விவசாயம், போக்குவரத்து, குடியிருப்புகள் மற்றும் நகரமயமாக்கலுக்கு ஏற்றதாக உள்ளது.
🔗 TNPSC Key Link

வடக்கு சமவெளிகள் → வண்டல் படிவச் சமவெளி

2. வடக்கு சமவெளிகளின் தோற்றம்
  • உயர்ந்து கொண்டிருந்த இமயமலை அதன் தெற்கில் ஒரு பெரிய முன்நிலப் பள்ளத்தை உருவாக்கியது.
  • இமயமலையிலிருந்து இறங்கிய ஆறுகள் மிகப்பெரிய அளவில் படிவப் பொருட்களை கொண்டு வந்தன.
  • பல மில்லியன் ஆண்டுகளில் இந்தப் படிவங்கள் அந்தப் பள்ளத்தை படிப்படியாக நிரப்பின.
  • மீண்டும் மீண்டும் ஏற்பட்ட படிவச் சேர்க்கை பரந்த சிந்து–கங்கை–பிரம்மபுத்திரா சமவெளியை உருவாக்கியது.
🔗 TNPSC Key Link

முன்நிலப் பள்ளம் + நதிப் படிவு → வடக்கு சமவெளிகள்

3. உருவாக்கத்திற்கு காரணமான முக்கிய நதி அமைப்புகள்

வடக்கு சமவெளிகள் முக்கியமாக பின்வரும் நதி அமைப்புகளால் உருவாக்கப்பட்டன:

  • சிந்து நதி அமைப்பு.
  • கங்கை நதி அமைப்பு.
  • பிரம்மபுத்திரா நதி அமைப்பு.
📌 Must-Memorise

வடக்கு சமவெளிகள் → சிந்து + கங்கை + பிரம்மபுத்திரா

4. வடக்கு சமவெளிகளின் பரப்பு
  • இந்த சமவெளிகள் மேற்கிலிருந்து கிழக்காக சுமார் 2,400 கி.மீ. நீளத்திற்கு பரவியுள்ளன.
  • அவற்றின் அகலம் பகுதியைப் பொறுத்து மாறுகிறது.
  • பொதுவாக கிழக்குப் பகுதிகளை விட மேற்கு மற்றும் மத்திய பகுதிகளில் அவை அகலமாக உள்ளன.
  • அவற்றின் மொத்த பரப்பளவு மிகப் பெரியது; இந்திய மக்கள்தொகையின் குறிப்பிடத்தக்க பகுதியை தாங்குகிறது.
5. பொதுவான நிலஅமைப்பு
  • இந்த சமவெளிகள் கிட்டத்தட்ட சமமாகத் தோன்றுகின்றன.
  • ஆனால் அவற்றில் மெதுவான பிராந்திய சரிவு உள்ளது.
  • இந்த நுண்மையான சரிவுகளுக்கு ஏற்ப ஆறுகள் பாய்கின்றன.
  • சிறிய உயர வேறுபாடுகள்கூட வடிகால், வெள்ளம் மற்றும் குடியிருப்புகளை பாதிக்கின்றன.
6. வண்டல் படிவு
  • வண்டல் என்பது ஆறுகளால் படியவைக்கப்படும் உறுதிப்படாத பொருட்களாகும்.
  • இதில் அடங்குபவை:
  • மணல்.
  • வண்டல் துகள்.
  • களிமண்.
  • சரளைக்கல்.
  • வடக்கு சமவெளிகளில் மிக ஆழமான வண்டல் படிவங்கள் உள்ளன.
  • செயலில் உள்ள வெள்ளச் சமவெளிகளில் இந்தப் படிவங்கள் காலந்தோறும் புதுப்பிக்கப்படுகின்றன.
7. சமவெளிகளின் வளம்
  • வண்டல் மண் பொதுவாக வளமானது.
  • நுண்ணிய படிவங்களில் பல பயனுள்ள கனிம ஊட்டச்சத்துகள் உள்ளன.
  • பல வெள்ளச் சமவெளிகளில் ஆற்றுப் படிவு மண்ணை தொடர்ந்து புதுப்பிக்கிறது.
  • பரந்த பாசன வசதியும் விவசாயத்தை மேலும் ஆதரிக்கிறது.
8. முக்கிய நிலவடிவப் பிரிவுகள்

வடக்கு சமவெளிகள் பொதுவாக பின்வருமாறு பிரிக்கப்படுகின்றன:

  • பஞ்சாப் சமவெளி.
  • கங்கை சமவெளி.
  • பிரம்மபுத்திரா சமவெளி.
📌 Must-Memorise

வடக்கு சமவெளிகள் → பஞ்சாப் + கங்கை + பிரம்மபுத்திரா

9. பஞ்சாப் சமவெளி
  • பஞ்சாப் சமவெளி வடக்கு சமவெளிகளின் வடமேற்குப் பகுதியில் உள்ளது.
  • இது முக்கியமாக சிந்து மற்றும் அதன் துணைநதிகளால் உருவானது.
  • வரலாற்றுச் சிறப்புமிக்க பஞ்சாப் சமவெளியின் பெரும் பகுதி இன்று பாகிஸ்தானில் உள்ளது.
  • இந்தியப் பகுதி முக்கியமாக பஞ்சாப், ஹரியானா மற்றும் அருகிலுள்ள பகுதிகளில் உள்ளது.
10. சிந்து துணைநதிகளும் பஞ்சாப் சமவெளியும்

முக்கியமான ஆறுகள்:

  • ஜீலம்.
  • செனாப்.
  • ரவி.
  • பியாஸ்.
  • சட்லெஜ்.

இந்த ஆறுகள் பஞ்சாப் சமவெளி உருவாகுவதற்கு பங்களித்தன.

11. பஞ்சாப் என்ற சொல்லின் பொருள்
  • பஞ்சாப் என்ற சொல் பாரசீகச் சொற்களிலிருந்து வந்தது:
  • பஞ்ச் → ஐந்து.
  • ஆப் → நீர்.
  • வரலாற்றில் இது ஐந்து ஆறுகளின் நிலம் என்று பொருள்படும்.
🔗 TNPSC Key Link

பஞ்சாப் → ஐந்து ஆறுகளின் நிலம்

12. தோஆப்
  • தோஆப் என்பது இரண்டு ஆறுகளுக்கு இடையில் உள்ள நிலப்பகுதி.
  • இந்தச் சொல் பாரசீக மொழியிலிருந்து வந்தது:
  • தோ → இரண்டு.
  • ஆப் → நீர்.
  • பஞ்சாப் மற்றும் கங்கை சமவெளிகளில் தோஆப்கள் முக்கிய நிலவடிவங்களாகும்.
🔗 TNPSC Key Link

தோஆப் → இரண்டு ஆறுகளுக்கிடையிலான நிலம்

13. புகழ்பெற்ற பஞ்சாப் தோஆப்கள்

பாரம்பரிய பஞ்சாப் தோஆப்களில் அடங்குபவை:

  • பிஸ்ட் / ஜலந்தர் தோஆப்.
  • பாரி தோஆப்.
  • ரச்சனா தோஆப்.
  • சாஜ் தோஆப்.
  • சிந்து சாகர் தோஆப்.
  • இவற்றில் சில பெரும்பாலும் இன்றைய பாகிஸ்தானில் உள்ளன.
14. கங்கை–யமுனை தோஆப்
  • கங்கை மற்றும் யமுனை ஆறுகளுக்கு இடையிலான நிலப்பகுதி கங்கை–யமுனை தோஆப் எனப்படுகிறது.
  • இது இந்தியாவின் மிக முக்கியமான விவசாயப் பகுதிகளில் ஒன்றாகும்.
  • இது முக்கியமாக உத்தரப் பிரதேசத்தில் உள்ளது.
🔗 TNPSC Key Link

கங்கை + யமுனை → கங்கை–யமுனை தோஆப்

15. கங்கை சமவெளி
  • வடக்கு சமவெளிகளின் மிகப்பெரிய பகுதியை கங்கை சமவெளி கொண்டுள்ளது.
  • இது உத்தரப் பிரதேசம், பீகார் மற்றும் மேற்கு வங்கத்தின் பெரும்பகுதியில் பரவியுள்ளது.
  • அருகிலுள்ள மாநிலங்களிலும் இதன் தாக்கம் காணப்படுகிறது.
  • கங்கை மற்றும் அதன் துணைநதிகள் இப்பகுதியில் தடிமனான வண்டல் படிவங்களை சேர்த்துள்ளன.
16. மேல் கங்கை சமவெளி
  • மேல் கங்கை சமவெளி முக்கியமாக மேற்கு மற்றும் மத்திய உத்தரப் பிரதேசத்தில் உள்ளது.
  • யமுனை, கங்கை மற்றும் அவற்றின் துணைநதிகள் இப்பகுதியை வடிகாலாக்குகின்றன.
  • இங்கு தீவிரமான விவசாயம் நடைபெறுகிறது.
17. மத்திய கங்கை சமவெளி
  • மத்திய கங்கை சமவெளி முக்கியமாக கிழக்கு உத்தரப் பிரதேசம் மற்றும் பீகாரில் உள்ளது.
  • முக்கிய ஆறுகளில் காக்ரா, கண்டக், கோசி மற்றும் சோன் அடங்கும்.
  • இந்தப் பகுதியின் சில இடங்களில் வெள்ளம் பொதுவானது.
18. கீழ் கங்கை சமவெளி
  • கீழ் கங்கை சமவெளி முக்கியமாக மேற்கு வங்கத்தில் உள்ளது.
  • வங்காள விரிகுடாவை நோக்கிச் செல்லச் செல்ல நிலப்பரப்பு தாழ்ந்து, டெல்டா தன்மை அதிகரிக்கிறது.
  • தெற்குப் பகுதியில் கங்கை–பிரம்மபுத்திரா டெல்டா ஆதிக்கம் செலுத்துகிறது.
19. பிரம்மபுத்திரா சமவெளி
  • பிரம்மபுத்திரா சமவெளி முக்கியமாக அசாமில் உள்ளது.
  • இது நீளமான, குறுகிய வண்டல் பள்ளத்தாக்காகும்.
  • இருபுறமும் மலைகளும் குன்றுகளும் சூழ்ந்துள்ளன.
  • பிரம்மபுத்திரா மற்றும் அதன் துணைநதிகள் பெருமளவு படிவங்களை சேர்க்கின்றன.
🔗 TNPSC Key Link

பிரம்மபுத்திரா சமவெளி → அசாம் பள்ளத்தாக்கு

20. பிரம்மபுத்திரா வெள்ளச் சமவெளி
  • பிரம்மபுத்திரா மிக அதிகமான படிவச் சுமையை கொண்டு செல்கிறது.
  • அதன் ஆற்றுப்பாதை அடிக்கடி மாறுகிறது.
  • மணற்படுகைகளும் நதி தீவுகளும் பொதுவாக காணப்படுகின்றன.
  • பருவகால வெள்ளம் முக்கிய அம்சமாகும்.
21. நதி தீவுகள்
  • நதி வாய்க்காலுக்குள் படிவு சேர்வதால் நதி தீவுகள் உருவாகின்றன.
  • பிரம்மபுத்திராவில் பல பெரிய நதி தீவுகள் உள்ளன.
  • அசாமில் உள்ள மாஜுலி புகழ்பெற்ற எடுத்துக்காட்டாகும்.
🔗 TNPSC Key Link

மாஜுலி → பிரம்மபுத்திரா → அசாம்

22. பாபர் பட்டை
  • பாபர் பகுதி சிவாலிக் மலை அடிவாரத்தை ஒட்டி அமைந்துள்ளது.
  • இது பொதுவாக குறுகிய பட்டையாக இருக்கும்.
  • மலைகளிலிருந்து இறங்கும் ஆறுகள் கூழாங்கற்கள், சரளைக்கற்கள் மற்றும் கரடுமுரடான பொருட்களை இங்கு படியவைக்கின்றன.
  • இந்தப் படிவங்கள் மிக அதிக ஊடுருவும் தன்மை கொண்டவை.
📌 Must-Memorise

பாபர் → கரடுமுரடான கூழாங்கற்கள் + ஊடுருவும் தன்மை

23. பாபரில் நீரோடைகள் மறைதல்
  • பாபர் பகுதியில் ஆறுகளும் நீரோடைகளும் பெரும்பாலும் நிலத்தின் கீழ் மறைந்து விடுகின்றன.
  • கரடுமுரடான, துளையுள்ள படிவங்களின் வழியாக நீர் ஊடுருவுகிறது.
  • இது பாபரின் முக்கிய அடையாள அம்சங்களில் ஒன்றாகும்.
🔗 TNPSC Key Link

24. தேராய் பட்டை
  • தேராய் பகுதி பாபரின் உடனடி தெற்கில் அமைந்துள்ளது.
  • பாபரில் நிலத்தடியில் சென்ற நீரோடைகள் இங்கு மீண்டும் மேற்பரப்பிற்கு வருகின்றன.
  • இப்பகுதி சதுப்பு மற்றும் நீர்தேக்கம் நிறைந்ததாக உள்ளது.
  • முன்னர் இது அடர்ந்த காடுகளையும் வனவிலங்குகளையும் ஆதரித்தது.
📌 Must-Memorise

தேராய் → நீரோடைகள் மீண்டும் தோன்றும் + சதுப்பு

25. பாபர் vs தேராய்

பாபர்:

  • வடக்கு.
  • கரடுமுரடான பொருட்கள்.
  • ஊடுருவும் தன்மை.
  • நீரோடைகள் மறையும்.

தேராய்:

  • தெற்கு.
  • நுண்ணிய படிவங்கள்.
  • சதுப்பு நிலம்.
  • நீரோடைகள் மீண்டும் தோன்றும்.

26. பாங்கர்

  • இது பொதுவாக செயலில் உள்ள வெள்ளச் சமவெளிகளை விட சற்றே உயர்ந்த மேடுகளில் காணப்படுகிறது.
  • இது ஆண்டுதோறும் வெள்ளத்தால் புதுப்பிக்கப்படுவதில்லை.
  • இதில் சுண்ணாம்புச் சேர்மக் கட்டிகள் அடிக்கடி காணப்படுகின்றன.

27. கங்கர்

  • இது குறிப்பாக பாங்கருடன் தொடர்புடையது.

28. காதர்
  • காதர் என்பது புதிய வண்டல் படிவம்.
  • இது செயலில் உள்ள வெள்ளச் சமவெளிகளில் காணப்படுகிறது.
  • வெள்ளத்தின் போது இது படியவைக்கப்படுகிறது அல்லது புதுப்பிக்கப்படுகிறது.
  • பழைய வண்டலை விட இது பொதுவாக அதிக வளம் கொண்டது.
📌 Must-Memorise

காதர் → புதிய வண்டல் படிவு

29. பாங்கர் vs காதர்

பாங்கர்:

  • பழைய வண்டல்.
  • உயர்ந்த மேடு.
  • கங்கர் பொதுவாக காணப்படும்.
  • வெள்ளம் குறைவாக ஏற்படும்.

காதர்:

  • புதிய வண்டல்.
  • தாழ்ந்த வெள்ளச் சமவெளி.
  • வெள்ளத்தால் புதுப்பிக்கப்படும்.
  • மிகவும் வளமானது.
30. வெள்ளச் சமவெளிகள்
  • வெள்ளச் சமவெளிகள் ஆறுகளின் அருகிலுள்ள தாழ்வான நிலப்பகுதிகள்.
  • இவை காலந்தோறும் வெள்ளத்தில் மூழ்குகின்றன.
  • வெள்ளத்தின் போது நுண்ணிய படிவங்கள் சேர்க்கப்படுகின்றன.
  • வெள்ளச் சமவெளிகள் வளமானவை; அதே நேரத்தில் பேரிடர் அபாயமும் கொண்டவை.
31. இயற்கை கரையணைகள்
  • இயற்கை கரையணைகள் ஆற்றங்கரைகளில் இயற்கையாக உருவாகும் உயர்ந்த மேடுகளாகும்.
  • வெள்ளத்தின் போது கரடுமுரடான படிவங்கள் ஆற்றுப்பாதைக்கு அருகே படியவைக்கப்படுகின்றன.
  • மீண்டும் மீண்டும் படிவு சேர்வதால் உயர்ந்த கரைகள் படிப்படியாக உருவாகின்றன.

32. பின்சதுப்பு நிலங்கள்
  • இயற்கை கரையணைகளின் பின்னால் உள்ள தாழ்வான, வடிகால் குறைந்த பகுதிகள் பின்சதுப்பு நிலங்கள் எனப்படுகின்றன.
  • இவை நீண்ட காலம் நீர் தேங்கிய நிலையில் இருக்கலாம்.
33. ஆற்று வளைவுகள்
  • ஆற்று வளைவுகள் என்பது ஆற்றுப்பாதையில் உருவாகும் வளைந்த சுருள்கள்.
  • மெதுவான சரிவுள்ள சமவெளிகளில் இவை பொதுவாக காணப்படுகின்றன.
  • வெளிப்புற வளைவுகளில் முக்கியமாக அரிப்பு நடைபெறும்.
  • உள்புற வளைவுகளில் முக்கியமாக படிவு சேர்கிறது.
34. ஆக்ஸ்போ ஏரிகள்
  • ஆறு ஒரு வளைவின் குறுகிய கழுத்துப் பகுதியை வெட்டி புதிய பாதை உருவாக்கும்போது ஆக்ஸ்போ ஏரி உருவாகிறது.
  • கைவிடப்பட்ட வளைவு முதன்மை ஆற்றுப்பாதையிலிருந்து பிரிகிறது.
  • முதிர்ந்த வெள்ளச் சமவெளிகளில் இவை பொதுவான நிலவடிவங்களாகும்.
📌 Must-Memorise

35. பின்னல் ஆற்றுப்பாதைகள்
  • பின்னல் ஆற்றில் படிவத் தடுப்புகளால் பிரிக்கப்பட்ட பல ஆற்றுப்பாதைகள் உருவாகின்றன.
  • படிவச் சுமை அதிகமாகவும் ஆற்றுப்பாதை நிலைமைகள் நிலையற்றதாகவும் இருக்கும் போது பின்னல் வடிவம் உருவாகிறது.
  • பிரம்மபுத்திரா பொதுவாக பின்னல் ஆற்றுப்பாதை பண்புகளை காட்டுகிறது.
36. வண்டல் விசிறிகள்
  • மலைகளிலிருந்து வரும் நீரோடைகள் சமமான நிலப்பரப்பில் நுழையும் இடங்களில் வண்டல் விசிறிகள் உருவாகின்றன.
  • நீரோட்ட வேகம் குறைகிறது.
  • கரடுமுரடான படிவங்கள் விசிறி வடிவில் படியவைக்கப்படுகின்றன.
  • மலை அடிவாரப் பகுதிகளில் இவை பொதுவாக காணப்படுகின்றன.
37. மலைஅடி மண்டலம்
  • மலைஅடி மண்டலம் மலைகளின் அடிப்பகுதியில் அமைந்துள்ளது.
  • பாபரை ஒரு முக்கிய மலைஅடி படிவப் பட்டையாகக் குறிப்பிடலாம்.
38. கங்கை–பிரம்மபுத்திரா டெல்டா
  • கங்கை மற்றும் பிரம்மபுத்திரா நதி அமைப்புகள் உலகின் மிகப்பெரிய டெல்டா பகுதிகளில் ஒன்றை உருவாக்குகின்றன.
  • இது இந்தியா மற்றும் வங்காளதேசம் முழுவதும் பரவியுள்ளது.
  • பல கிளைநதிகள் கீழ்ப்பகுதி நதி அமைப்பை பல பிரிவுகளாகப் பிரிக்கின்றன.

39. சுந்தர்பன்ஸ்

  • இந்தப் பகுதியை அலைவாய்க்கால்களும் கிளைநதிகளும் கடந்து செல்கின்றன.

41. டெல்டா vs எஸ்ட்யூரி

டெல்டா:

  • படிவச் சேர்க்கை நிலவடிவு.
  • ஆறு பல கிளைநதிகளாகப் பிரிகிறது.
  • அதிக அளவு படிவம் சேர்கிறது.

எஸ்ட்யூரி:

  • புனல் வடிவிலான அல்லது அலைச்சலால் பாதிக்கப்படும் ஆற்றுமுகம்.
  • பொதுவாக பரந்த கிளைநதி வலையமைப்பு இருக்காது.

45. கோசி நதி
  • கோசி கங்கையின் முக்கியமான இமயமலைத் துணைநதியாகும்.
  • இது நேபாளம் மற்றும் பீகார் வழியாக பாய்கிறது.
  • வரலாற்றில் இது சமவெளிகளில் தனது பாதையை பலமுறை மாற்றியுள்ளது.
  • பீகாரில் ஏற்படும் கடுமையான வெள்ளங்களுக்கு இது பெயர் பெற்றது.
🔗 TNPSC Key Link

கோசி → பீகார் வெள்ளம்

46. "பீகாரின் துயரம்"
  • மீண்டும் மீண்டும் ஏற்படும் வெள்ளங்களும் ஆற்றுப்பாதை மாற்றங்களும் காரணமாக கோசி பாரம்பரியமாக "பீகாரின் துயரம்" எனப்படுகிறது.

47. தாமோதர் நதி
  • தாமோதர் ஜார்கண்ட் மற்றும் மேற்கு வங்கம் வழியாக பாய்கிறது.
  • வரலாற்றில் இது அழிவூட்டும் வெள்ளங்களுடன் தொடர்புடையதாக இருந்தது.
  • இது பாரம்பரியமாக "வங்கத்தின் துயரம்" எனப்பட்டது.

48. பிரம்மபுத்திரா படிவச் சேர்க்கை
  • இளம் மலைகளிலிருந்து பிரம்மபுத்திரா மிக அதிகமான படிவச் சுமையை கொண்டு வருகிறது.
  • படிவு சேர்வதால் மணற்படுகைகளும் தீவுகளும் உருவாகின்றன.
  • கரையரிப்பும் ஆற்றுப்பாதை இடமாற்றமும் பொதுவாக நடைபெறுகின்றன.
  • மழைக்காலத்தில் வெள்ளம் அடிக்கடி ஏற்படுகிறது.
49. பஞ்சாப் சமவெளியின் வடிகால்
  • பஞ்சாப் சமவெளியின் பெரும்பகுதியை சிந்து நதி அமைப்பின் ஆறுகள் வடிகாலாக்குகின்றன.
  • பரந்த பாசன வசதி விவசாயத்தை ஆதரிக்கிறது.
  • கால்வாய் பாசனம் குறிப்பாக முக்கியமானது.
50. கங்கை சமவெளியின் வடிகால்
  • கங்கை மற்றும் அதன் துணைநதிகள் அடர்த்தியான வடிகால் வலையமைப்பை உருவாக்குகின்றன.
  • சமவெளியின் பெரும்பகுதியில் ஆற்றுச் சரிவு குறைவாக உள்ளது.
  • ஆற்று வளைவுகளும் வெள்ளச் சமவெளிகளும் பொதுவாக காணப்படுகின்றன.
51. பிரம்மபுத்திரா பள்ளத்தாக்கின் நிலஅமைப்பு
  • அசாமின் பிரம்மபுத்திரா பள்ளத்தாக்கை குன்றுகள் சூழ்ந்துள்ளன.
  • கங்கை சமவெளியுடன் ஒப்பிடும்போது இந்தப் பள்ளத்தாக்கு ஒப்பீட்டளவில் குறுகியது.
  • சுற்றியுள்ள மலைகளிலிருந்து பல துணைநதிகள் இறங்கி வருகின்றன.
52. வளமான விவசாயப் பகுதி

வடக்கு சமவெளிகளின் முக்கிய பயிர்கள்:

  • நெல்.
  • கோதுமை.
  • கரும்பு.
  • மக்காச்சோளம்.
  • பருப்பு வகைகள்.
  • எண்ணெய் விதைகள்.
  • கிழக்குப் பகுதிகளில் சணல்.
53. கோதுமைப் பட்டை
  • பஞ்சாப், ஹரியானா மற்றும் மேற்கு உத்தரப் பிரதேசம் முக்கிய கோதுமை உற்பத்திப் பகுதிகளாகும்.
  • பாசனமும் வளமான வண்டல் மண்ணும் அதிக உற்பத்தியை ஆதரிக்கின்றன.
  • குளிர்கால நிலை ரபி கோதுமை சாகுபடிக்கு ஏற்றது.
54. நெல் பட்டை
  • அதிக ஈரப்பதமுள்ள கிழக்கு சமவெளிகளை நோக்கிச் செல்லச் செல்ல நெல் சாகுபடியின் முக்கியத்துவம் அதிகரிக்கிறது.
  • பீகார், மேற்கு வங்கம் மற்றும் அசாமில் பரந்த நெல் சாகுபடி உள்ளது.
  • வட இந்தியாவின் பாசன வசதியுள்ள பகுதிகளிலும் நெல் முக்கியமான பயிராகும்.
55. கரும்பு
  • உத்தரப் பிரதேசம் முக்கிய கரும்பு உற்பத்திப் பகுதியாகும்.
  • வளமான சமவெளி, பாசனம் மற்றும் வெப்பமான வளர்ச்சி நிலை கரும்புச் சாகுபடிக்கு ஏற்றவை.
56. சணல்
  • சணல் சாகுபடி கீழ் கங்கை–பிரம்மபுத்திரா டெல்டா பகுதியுடன் நெருங்கிய தொடர்புடையது.
  • மேற்கு வங்கம் இதில் குறிப்பாக முக்கியமானது.
  • வெப்பமான, ஈரமான காலநிலையும் வண்டல் மண்ணும் சணல் சாகுபடிக்கு ஏற்றவை.

57. மக்கள் அடர்த்தி
  • வடக்கு சமவெளிகளில் இந்தியாவின் மிக அதிக மக்கள் அடர்த்தி கொண்ட பகுதிகளில் சில உள்ளன.
  • காரணங்கள்:
  • வளமான மண்.
  • நீர் கிடைப்புத் திறன்.
  • சமமான நிலப்பரப்பு.
  • விவசாயம்.
  • போக்குவரத்து.
  • நகர வளர்ச்சி.
58. நகர மையங்கள்

வடக்கு சமவெளிகளில் அல்லது அதன் அருகில் உள்ள முக்கிய நகரங்கள்:

  • டெல்லி.
  • சண்டிகர்.
  • லக்னோ.
  • கான்பூர்.
  • பிரயாக்ராஜ்.
  • வாரணாசி.
  • பாட்னா.
  • கொல்கத்தா.
  • குவாஹட்டி.
59. போக்குவரத்து நன்மைகள்
  • சமமான நிலப்பரப்பு சாலை மற்றும் இரயில்பாதை அமைப்பை எளிதாக்குகிறது.
  • முக்கிய போக்குவரத்து வழித்தடங்கள் இந்த சமவெளிகளை கடந்து செல்கின்றன.
  • சில பகுதிகளில் வழிசெலுத்தக்கூடிய ஆறுகளும் போக்குவரத்திற்கு பயன்படுகின்றன.
60. உள்நாட்டு நீர்வழிகள்
  • கங்கை மற்றும் பிரம்மபுத்திரா நதி அமைப்புகள் உள்நாட்டு நீர்ப் போக்குவரத்திற்கு முக்கியமானவை.
  • குறைந்த சரிவும் பெரிய ஆற்றுப்பாதைகளும் சில பகுதிகளில் நீர்வழிப் போக்குவரத்திற்கு ஏற்றவை.
61. பாசனம்

முக்கிய பாசன ஆதாரங்கள்:

  • கால்வாய்கள்.
  • குழாய் கிணறுகள்.
  • கிணறுகள்.
  • நதி திட்டங்கள்.
  • வண்டல் நீர்த்தேக்கப் படுகைகள் பல பகுதிகளில் அதிக நிலத்தடி நீரை வழங்குகின்றன.
62. நிலத்தடி நீர்
  • தடிமனான வண்டல் படிவங்கள் பெருமளவு நிலத்தடி நீரை சேமிக்க முடியும்.
  • ஆழம் குறைந்த நீர்த்தேக்கப் படுகைகள் பாசனத்திற்கும் வீட்டு நீர் தேவைக்கும் பரவலாக பயன்படுத்தப்படுகின்றன.
  • அதிக அளவு நீர் எடுப்பதால் நிலத்தடி நீர்மட்டம் குறையலாம்.
63. வெள்ள அபாயம்
  • வடக்கு சமவெளிகளின் முக்கிய இயற்கை அபாயங்களில் வெள்ளம் ஒன்றாகும்.
  • காரணங்கள்:
  • அதிக மழைக்கால மழை.
  • இமயமலையிலிருந்து அதிக நீரோட்டம்.
  • படிவச் சேர்க்கை.
  • ஆற்றுப்பாதை மாற்றங்கள்.
  • கரையணை உடைதல்.
  • மோசமான வடிகால்.
64. வெள்ளம் அதிகம் ஏற்படும் பகுதிகள்

குறிப்பாக வெள்ளம் அதிகம் ஏற்படும் பகுதிகள்:

  • பீகார் சமவெளிகள்.
  • கிழக்கு உத்தரப் பிரதேசம்.
  • அசாமின் பிரம்மபுத்திரா பள்ளத்தாக்கு.
  • மேற்கு வங்கத்தின் சில பகுதிகள்.
65. ஆற்றங்கரை அரிப்பு
  • பிரம்மபுத்திரா மற்றும் கங்கையின் முக்கிய துணைநதிகளின் கரைகளில் ஆற்றங்கரை அரிப்பு மிகவும் தீவிரமாக உள்ளது.
  • ஆற்றுப்பாதை இடமாற்றத்தால் முழு குடியிருப்புகளும் விவசாய நிலங்களும் இழக்கப்படலாம்.
66. கரையணைகள்
  • ஆற்றுவெள்ளத்தை கட்டுப்படுத்த கரையணைகள் கட்டப்படுகின்றன.
  • மிதமான வெள்ளத்திலிருந்து அவை பகுதிகளை பாதுகாக்க முடியும்.
  • ஆனால் கரையணை உடைதல் கடுமையான உள்ளூர் சேதத்தை ஏற்படுத்தலாம்.
  • கரையணைக்குள் உள்ள ஆற்றுப்பாதைகளில் படிவு சேர்வதும் நீண்டகால சிக்கல்களை உருவாக்கலாம்.
67. நீர்தேக்கம்
  • நிலத்தடி நீர்மட்டம் நிலப்பரப்பிற்கு அருகில் உயரும்போது நீர்தேக்கம் ஏற்படுகிறது.
  • மோசமான வடிகாலும் அளவுக்கு மீறிய பாசனமும் இதற்கு காரணமாக இருக்கலாம்.
  • நீர்தேக்கம் மண்ணின் காற்றோட்டத்தையும் பயிர் உற்பத்தியையும் குறைக்கிறது.
68. உவர்ப்பு பிரச்சினைகள்
  • சில பாசனப் பகுதிகளில் ஆவியாகுதல் காரணமாக மண்ணின் மேற்பரப்பிற்கு அருகில் உப்புகள் தேங்குகின்றன.
  • மோசமான வடிகால் மண் உவர்ப்பை மேலும் அதிகரிக்கலாம்.
  • இத்தகைய பிரச்சினைகள் வடமேற்கு சமவெளிகளின் வறண்ட மற்றும் அரைவறண்ட பகுதிகளில் குறிப்பாக காணப்படுகின்றன.
69. சமவெளிகளும் பசுமைப் புரட்சியும்
  • பஞ்சாப், ஹரியானா மற்றும் மேற்கு உத்தரப் பிரதேசம் பசுமைப் புரட்சியின் முக்கிய மையங்களாக ஆனது.
  • வளமான வண்டல் மண், பாசனம், அதிக மகசூல் தரும் விதைகள் மற்றும் உரங்கள் தீவிர விவசாயத்தை ஆதரித்தன.
  • விவசாயம் பின்னர் விரிவாகப் பார்க்கப்படும்.
70. பஞ்சாப்–ஹரியானா சமவெளி

முக்கிய அம்சங்கள்:

  • சமமான நிலப்பரப்பு.
  • பரந்த பாசன வசதி.
  • கோதுமை–நெல் சாகுபடி.
  • அதிக விவசாய உற்பத்தித்திறன்.
  • அடர்த்தியான சாலை மற்றும் கால்வாய் வலையமைப்புகள்.
71. உத்தரப் பிரதேச சமவெளி
  • கங்கை சமவெளியின் பெரிய பகுதியை உத்தரப் பிரதேசம் கொண்டுள்ளது.
  • கங்கை, யமுனை, காக்ரா, கோமதி உள்ளிட்டவை முக்கிய ஆறுகள்.
  • விவசாயமும் மக்கள் அடர்த்தியும் அதிகமாக உள்ளன.
72. பீகார் சமவெளி
  • பீகாரை பல இமயமலை ஆறுகள் கடந்து செல்கின்றன.
  • கோசி, கண்டக் மற்றும் காக்ரா வெள்ளத்திற்கு காரணமாகின்றன.
  • இந்த சமவெளிகள் மிகவும் வளமானவை.
  • ஆற்றுப்பாதை நிலையின்மை ஒரு முக்கிய சவாலாகும்.
73. மேற்கு வங்க சமவெளி
  • மேற்கு வங்கத்தில் கீழ் கங்கை சமவெளியும் டெல்டா பகுதியும் உள்ளன.
  • சணலும் நெல்லும் முக்கிய பயிர்கள்.
  • தெற்குப் பகுதி சுந்தர்பன்ஸ் டெல்டாவுடன் இணைகிறது.
74. அசாம் சமவெளி
  • அசாமின் முக்கிய தாழ்நிலப்பகுதி பிரம்மபுத்திரா பள்ளத்தாக்காகும்.
  • வெள்ளச் சமவெளிகளில் மட்டும் அல்லாமல் பள்ளத்தாக்கை ஒட்டிய ஏற்ற உயர்நிலங்களிலும் சரிவுகளிலும் தேயிலை பரவலாக பயிரிடப்படுகிறது.
  • சமவெளிகளில் நெல் முக்கியமானது.
  • வெள்ளம் மீண்டும் மீண்டும் ஏற்படுகிறது.
75. பழைய மற்றும் புதிய வண்டல் படிவப் பரவல்
  • பாங்கர் பொதுவாக சற்றே உயர்ந்த பகுதிகளில் காணப்படுகிறது.
  • காதர் தாழ்ந்த, செயலில் உள்ள வெள்ளச் சமவெளிகளில் காணப்படுகிறது.
  • இரண்டும் கங்கை சமவெளியில் பரவலாக காணப்படுகின்றன.
  • காதர் புதிய படிவங்களால் காலந்தோறும் புதுப்பிக்கப்படுகிறது.
76. காதரின் வளம்
  • நுண்ணிய வண்டல் துகள்கள் அடிக்கடி படிவதால் கனிமங்கள் மீண்டும் நிரம்புகின்றன.
  • எனவே காதர் பொதுவாக விவசாயத்திற்கு மிகவும் ஏற்றது.
  • ஆனால் செயலில் உள்ள வெள்ளச் சமவெளிகளில் மீண்டும் மீண்டும் வெள்ள அபாயமும் உள்ளது.
77. பாங்கர் மேற்பரப்பு
  • பாங்கர் மேற்பரப்புகள் பழமையானவை; பொதுவாக தற்போதைய வெள்ள நிலையை விட உயரமாக உள்ளன.
  • அவற்றில் முதிர்ந்த மண் காணப்படலாம்.
  • கங்கர் சேர்க்கை சில இடங்களில் வளத்தை குறைக்கலாம்.
78. தேராய் விவசாயம்
  • முன்னர் சதுப்பாக இருந்த பல தேராய் பகுதிகள் வடிகாலமைத்து சுத்தப்படுத்தப்பட்டுள்ளன.
  • இப்போது அவை விவசாயத்தையும் குடியிருப்புகளையும் ஆதரிக்கின்றன.
  • இப்பகுதியில் இன்னும் நிலத்தடி நீரும் ஈரப்பதமும் அதிகமாக உள்ளன.
79. தேராய் காடுகள்
  • வரலாற்றில் தேராய் பகுதி அடர்ந்த காடுகளையும் புல்வெளிகளையும் கொண்டிருந்தது.
  • இமயமலை அடிவாரப் பாதுகாக்கப்பட்ட பகுதிகளில் முக்கிய வனவிலங்கு வாழிடங்கள் இன்னும் உள்ளன.
80. பாபர் விவசாயம்
  • பாபரின் கரடுமுரடான படிவங்கள் மிகவும் நீர்ஊடுருவும் தன்மை கொண்டவை.
  • மேற்பரப்பு நீர் குறைவாக கிடைக்கிறது.
  • எனவே உடனடி தெற்கிலுள்ள தேராயை விட பாபரில் விவசாயம் குறைவாக தீவிரமானது.
81. வடக்கு சமவெளிகளும் ஆறுகளும்
  • ஆறுகள் சமவெளிகளின் எல்லைகளாக மட்டும் இருப்பதில்லை.
  • அரிப்பும் படிவச் சேர்க்கையும் மூலம் அவை சமவெளிகளை தொடர்ந்து மாற்றியமைக்கின்றன.
  • ஆற்றுப்பாதை இடமாற்றம் புதிய வெள்ளச் சமவெளிகள், கரையணைகள் மற்றும் கைவிடப்பட்ட வாய்க்கால்களை உருவாக்குகிறது.
82. ஆற்று வளைவு வெட்டுப்பாடு

வழக்கமான நிகழ்வுக்கோலம்:

  • ஆற்று வளைவு பெரிதாகிறது.
  • வளைவின் கழுத்துப் பகுதி குறுகுகிறது.
  • அதிக நீரோட்டத்தின் போது ஆறு அந்தக் கழுத்துப் பகுதியை வெட்டி புதிய பாதை எடுக்கிறது.
  • பழைய வளைவு கைவிடப்படுகிறது.
  • ஆக்ஸ்போ ஏரி உருவாகிறது.
83. நதித் தீவுகள் மற்றும் சார்ஸ்
  • பெரிய ஆறுகளுக்குள் தற்காலிக அல்லது அரைநிலையான படிவத் தீவுகள் உருவாகின்றன.
  • பிரம்மபுத்திரா மற்றும் கங்கை அமைப்புகளில் இத்தகைய படிவத் தீவுகள் பிராந்தியப் பயன்பாட்டில் 'சார்' என அழைக்கப்படுகின்றன.
  • இவை வெள்ளத்துக்கும் அரிப்புக்கும் மிகவும் பாதிக்கப்படக்கூடியவை.
84. டெல்டா தீவுகள்
  • கிளைநதிகளுக்கு இடையில் டெல்டா தீவுகள் உருவாகின்றன.
  • கீழ் கங்கை–பிரம்மபுத்திரா பகுதியில் இவை குறிப்பிடத்தக்க அளவில் காணப்படுகின்றன.
  • சுந்தர்பன்ஸில் அலைச்சலின் தாக்கம் அதிகமாக உள்ளது.
85. கீழ் டெல்டாவில் அலைச்சல் செயல்பாடு
  • கீழ் டெல்டாவின் வாய்க்கால்கள் அலைச்சலால் பாதிக்கப்படுகின்றன.
  • கடற்கரையை நோக்கிச் செல்லச் செல்ல உவர்ப்பு அதிகரிக்கிறது.
  • மாங்க்ரூவ் தாவரங்கள் அலைச்சல் மற்றும் உவர்நன்னீர் கலந்த சூழலுக்கு ஏற்ப தழுவியுள்ளன.
86. வடக்கு சமவெளிகளும் இயற்கைத் தாவர வளமும்
  • விவசாயம் மற்றும் குடியிருப்புகளுக்காக இயற்கைத் தாவர வளத்தின் பெரும்பகுதி அகற்றப்பட்டுள்ளது.
  • தேராய் காடுகள், ஆற்றங்கரைத் தாவரங்கள் மற்றும் ஈரநிலங்கள் இன்னும் முக்கிய சூழலியல் வாழிடங்களாக உள்ளன.
87. ஈரநிலங்கள்
  • வெள்ளச் சமவெளிகளில் பல ஈரநிலங்கள், சதுப்பு நிலங்கள், ஆக்ஸ்போ ஏரிகள் மற்றும் பருவகால நீர்நிலைகள் காணப்படுகின்றன.
  • இவை வெள்ளநீரை சேமிக்கின்றன.
  • மீன்கள், பறவைகள் மற்றும் பிற உயிரியல் பல்வகைத்தன்மைக்கு இவை ஆதரவாக உள்ளன.
88. ஈரநிலங்களின் முக்கியத்துவம்

வெள்ளச் சமவெளி ஈரநிலங்கள்:

  • வெள்ள உச்சநிலையை குறைக்கின்றன.
  • நிலத்தடி நீரை மீள்நிரப்புகின்றன.
  • மீன்பிடி வளத்தை வழங்குகின்றன.
  • இடம்பெயரும் பறவைகளை ஆதரிக்கின்றன.
  • படிவங்களையும் ஊட்டச்சத்துகளையும் சேமிக்கின்றன.
89. சமவெளி உருவாக்கம் இன்னும் தொடர்கிறது
  • வடக்கு சமவெளிகள் புவியியல் ரீதியாக நிலையானவை அல்ல.
  • ஆறுகள் தொடர்ந்து படிவங்களை சேர்த்து வருகின்றன.
  • ஆற்றுப்பாதைகள் தொடர்ந்து இடம் மாறுகின்றன.
  • வெள்ளச் சமவெளிகளும் டெல்டாக்களும் தொடர்ந்து மாற்றமடைந்து வருகின்றன.

90. வடக்கு சமவெளிகளும் இமயமலையும்
  • சமவெளிகள் இமயமலையிலிருந்து வரும் படிவப் பொருட்களை மிகுந்த அளவில் சார்ந்துள்ளன.
  • இளம் இமயமலைப் பாறைகள் வேகமாக அரைகின்றன.
  • ஆறுகள் அரிந்த பொருட்களை தெற்கே கொண்டு செல்கின்றன.
  • இதனால் இமயமலை உயர்வும் சமவெளி உருவாக்கமும் நெருங்கிய தொடர்புடையவை.
91. சிந்து–கங்கை சமவெளி
  • சிந்து–கங்கை சமவெளி என்ற சொல் பொதுவாக சிந்து மற்றும் கங்கை நதி அமைப்புகளுடன் தொடர்புடைய பரந்த சமவெளிகளை குறிக்கிறது.
  • பெரிய புவியியல் விளக்கங்களில் பிரம்மபுத்திரா சமவெளியும் இந்த வடக்கு வண்டல் அமைப்புடன் சேர்த்து விவாதிக்கப்படுகிறது.
92. சிந்து–கங்கை–பிரம்மபுத்திரா சமவெளி
  • இந்தச் சொல் முழு வடக்கு வண்டல் பட்டையின் தொடர்ச்சியை வலியுறுத்துகிறது.
  • இது இந்தியா மற்றும் அண்டை தென் ஆசியப் பகுதிகளில் பரவியுள்ளது.
  • இது உலகின் முக்கிய நதித் தாழ்நிலப் பகுதிகளில் ஒன்றாகும்.
93. இந்திய பொருளாதாரத்திற்கான முக்கியத்துவம்

வடக்கு சமவெளிகள் பின்வருவனவற்றிற்கு பெரிய பங்களிப்பு செய்கின்றன:

  • உணவுத்தானிய உற்பத்தி.
  • கரும்புச் சாகுபடி.
  • சணல் உற்பத்தி.
  • பால் உற்பத்தி மற்றும் கால்நடை வளர்ப்பு.
  • தொழில்.
  • வாணிபம்.
  • நகர வளர்ச்சி.
  • போக்குவரத்து.
94. வரலாற்று முக்கியத்துவம்
  • நதி பள்ளத்தாக்குகள் வளமான நிலத்தையும் நீரையும் வழங்கின.
  • பல பண்டைய குடியிருப்புகளும் அரசுகளும் இந்த சமவெளிகளில் வளர்ந்தன.
  • கங்கை சமவெளி இந்தியாவின் முக்கிய வரலாற்று மற்றும் பண்பாட்டு மையங்களில் ஒன்றாக வளர்ந்தது.
95. மூலோபாய முக்கியத்துவம்
  • வடமேற்கு சமவெளிகள் வரலாற்றில் துணைக்கண்டத்திற்குள் நுழையும் முக்கிய நிலவழியாக இருந்தன.
  • இன்றைய சமவெளிகள் முக்கிய போக்குவரத்து மற்றும் பாதுகாப்பு வழித்தடங்களை ஆதரிக்கின்றன.
  • நதி அமைப்புகள் நீர் பாதுகாப்பிற்கு முக்கியமானவை.
96. வடக்கு சமவெளிகள் vs தீபகற்ப பீடபூமி

வடக்கு சமவெளிகள்:

  • இளம் நிலவடிவு.
  • வண்டல் அமைப்பு.
  • சமமானது.
  • படிவ நிலவடிவு.
  • வளமானது.

தீபகற்ப பீடபூமி:

  • பழமையானது.
  • படிகப் பாறைகள் கொண்டது.
  • சமமற்றது.
  • அரிப்பு / கட்டமைப்பு நிலவடிவு.
  • கனிம வளம் நிறைந்தது.
97. வடக்கு சமவெளிகள் vs இமயமலைப் பகுதி

வடக்கு சமவெளிகள்:

  • குறைந்த உயரம்.
  • அதிக மக்கள் அடர்த்தி.
  • பரந்த விவசாயம்.
  • எளிதான போக்குவரத்து.

இமயமலை:

  • அதிக உயர வேறுபாடு.
  • உயரப்பகுதிகளில் மக்கள் அடர்த்தி குறைவு.
  • செங்குத்தான சரிவுகள்.
  • கடினமான போக்குவரத்து.
98. வரைபடத்தில் கண்டறிய வேண்டிய தகவல்கள்

கண்டறிய வேண்டியவை:

  • பஞ்சாப் சமவெளி.
  • கங்கை சமவெளி.
  • பிரம்மபுத்திரா சமவெளி.
  • பாபர்.
  • தேராய்.
  • கங்கை–யமுனை தோஆப்.
  • கோசி.
  • தாமோதர்.
  • மாஜுலி.
  • சுந்தர்பன்ஸ்.
  • கங்கை–பிரம்மபுத்திரா டெல்டா.
99. TNPSC அதிக வாய்ப்புள்ள இணைப்புகள்
  • வடக்கு சமவெளிகள் → வண்டல்.
  • பாபர் → கூழாங்கற்கள்.
  • தேராய் → சதுப்பு.
  • பாங்கர் → பழைய வண்டல்.
  • காதர் → புதிய வண்டல்.
  • பாங்கர் → கங்கர்.
  • கங்கை–யமுனை → தோஆப்.
  • கோசி → பீகாரின் துயரம்.
  • தாமோதர் → வங்கத்தின் துயரம்.
  • மாஜுலி → பிரம்மபுத்திரா.
  • சுந்தர்பன்ஸ் → கங்கை–பிரம்மபுத்திரா டெல்டா.
  • மேற்கு வங்கம் → சணல்.

  • அசாம் பள்ளத்தாக்கு → பிரம்மபுத்திரா சமவெளி.
100. TNPSC Traps
  • வடக்கு சமவெளிகள் அரிப்பு சமவெளிகள் அல்ல; அவை படிவ சமவெளிகள்.
  • இவை முக்கியமாக சிந்து, கங்கை மற்றும் பிரம்மபுத்திரா நதி அமைப்புகளால் உருவானவை.
  • வண்டல் என்பது ஆறுகள் படியவைக்கும் பொருள்.
  • பாபர் சிவாலிக் மலைகளின் உடனடி தெற்கில் உள்ளது.
  • தேராய் பாபரின் தெற்கில் உள்ளது.
  • பாபரில் நீரோடைகள் மறைகின்றன.
  • தேராயில் நீரோடைகள் மீண்டும் தோன்றுகின்றன.
  • பாபர் கரடுமுரடானதும் நீர்ஊடுருவும் தன்மை கொண்டதும் ஆகும்.
  • தேராய் சதுப்பு நிலமாகும்.
  • பாங்கர் பழைய வண்டல்.
  • காதர் புதிய வண்டல்.
  • கங்கர் முக்கியமாக பாங்கருடன் தொடர்புடையது.
  • காதர் வெள்ளத்தால் புதுப்பிக்கப்படுகிறது.
  • தோஆப் என்பது இரண்டு ஆறுகளுக்கு இடையிலான நிலம்.
  • கங்கை–யமுனை தோஆப் முக்கியமாக உத்தரப் பிரதேசத்தில் உள்ளது.
  • பஞ்சாப் என்றால் ஐந்து ஆறுகளின் நிலம்.
  • கோசி 'பீகாரின் துயரம்' எனப்படுகிறது.
  • தாமோதர் பாரம்பரியமாக 'வங்கத்தின் துயரம்' எனப்படுகிறது.
  • மாஜுலி பிரம்மபுத்திராவுடன் தொடர்புடையது.
  • வெட்டப்பட்ட ஆற்று வளைவிலிருந்து ஆக்ஸ்போ ஏரி உருவாகிறது.
  • பிரம்மபுத்திராவில் பின்னல் ஆற்றுப்பாதைகள் பொதுவாக காணப்படுகின்றன.
  • துணைநதி முதன்மை ஆற்றில் சேர்கிறது.
  • கிளைநதி முதன்மை ஆற்றிலிருந்து விலகிச் செல்கிறது.
  • சுந்தர்பன்ஸ் டெல்டா சூழலில் அமைந்துள்ளது.
  • வடமேற்கு சமவெளிகளை விட கிழக்குப் பகுதியின் கீழ் சமவெளிகள் அதிக ஈரப்பதம் கொண்டவை.
  • வடக்கு சமவெளிகளில் விவசாய அடர்த்தியும் மக்கள் அடர்த்தியும் அதிகம்.
  • வெள்ளம் வளமான படிவங்களை வழங்கும் ஆதாரமும் முக்கிய அபாயமும் ஆகும்.
  • பாங்கர் மற்றும் காதர் இரண்டு வேறு ஆறுகள் அல்ல; அவை வண்டலின் வகைகள்.

Rapid Revision — TNPSC Most Expected
  • வடக்கு சமவெளிகள் முக்கியமாக எவ்வாறு உருவானது? → நதிப் படிவச் சேர்க்கையால்.
  • இதற்கு காரணமான முக்கிய நதி அமைப்புகள்? → சிந்து, கங்கை மற்றும் பிரம்மபுத்திரா.
  • வடக்கு சமவெளிகளை உருவாக்கும் முக்கிய பொருள்? → வண்டல்.
  • மூன்று முக்கிய பிரிவுகள்? → பஞ்சாப் சமவெளி, கங்கை சமவெளி மற்றும் பிரம்மபுத்திரா சமவெளி.
  • பஞ்சாப் சமவெளி முக்கியமாக எந்த நதி அமைப்புடன் தொடர்புடையது? → சிந்து நதி அமைப்பு.
  • பஞ்சாப் என்ற சொல்லின் பொருள்? → ஐந்து ஆறுகளின் நிலம்.
  • பஞ்சாபுடன் வரலாற்றில் தொடர்புடைய ஐந்து ஆறுகள்? → ஜீலம், செனாப், ரவி, பியாஸ் மற்றும் சட்லெஜ்.
  • தோஆப் என்றால் என்ன? → இரண்டு ஆறுகளுக்கு இடையிலான நிலப்பகுதி.
  • கங்கை–யமுனை தோஆப் முக்கியமாக எங்கு உள்ளது? → உத்தரப் பிரதேசம்.
  • வடக்கு சமவெளிகளின் மிகப்பெரிய பகுதி? → கங்கை சமவெளி.
  • பிரம்மபுத்திரா சமவெளி முக்கியமாக எங்கு உள்ளது? → அசாம்.
  • சிவாலிக் மலைகளின் உடனடி தெற்கில் உள்ள பட்டை? → பாபர்.
  • பாபரின் முக்கிய பொருள்? → கூழாங்கற்கள் மற்றும் கரடுமுரடான சரளைக்கற்கள்.
  • பாபரில் நீரோடைகள் ஏன் மறைகின்றன? → மிகவும் நீர்ஊடுருவும் படிவங்கள் காரணமாக.
  • பாபரின் தெற்கில் உள்ள பட்டை? → தேராய்.
  • தேராயின் முக்கிய பண்பு? → சதுப்பு மற்றும் நீர்தேக்கம்.
  • தேராயில் நீரோடைகளுக்கு என்ன நிகழ்கிறது? → அவை மீண்டும் மேற்பரப்பிற்கு வருகின்றன.
  • பழைய வண்டல் என்ன அழைக்கப்படுகிறது? → பாங்கர்.
  • புதிய வண்டல் என்ன அழைக்கப்படுகிறது? → காதர்.
  • கங்கர் எதில் காணப்படுகிறது? → பாங்கர்.
  • வெள்ளத்தால் புதுப்பிக்கப்படும் வண்டல் எது? → காதர்.
  • பொதுவாக அதிக வளமுடையது எது? → காதர்.
  • கங்கர் என்றால் என்ன? → சுண்ணாம்புச் சேர்மக் கட்டிகள்.
  • வெள்ளச் சமவெளி என்றால் என்ன? → ஆற்றருகே உள்ள, காலந்தோறும் வெள்ளமடையும் தாழ்வான நிலம்.
  • இயற்கை கரையணை எங்கு உருவாகிறது? → ஆற்றங்கரையில் படிவு சேர்வதால்.
  • ஆற்று வளைவுகள் பொதுவாக எங்கு காணப்படும்? → குறைந்த சரிவுள்ள சமவெளிகளில்.
  • ஆற்று வளைவு வெட்டப்பட்டால் என்ன உருவாகிறது? → ஆக்ஸ்போ ஏரி.
  • இந்தியாவில் பின்னல் ஆற்றுப்பாதைக்கு புகழ்பெற்ற ஆறு எது? → பிரம்மபுத்திரா.
  • வண்டல் விசிறி என்றால் என்ன? → மலைகளிலிருந்து சமவெளிக்கு வரும் நீரோடை உருவாக்கும் விசிறி வடிவப் படிவு.
  • கீழ் கங்கை–பிரம்மபுத்திரா பகுதி எதை உருவாக்குகிறது? → பெரிய டெல்டா.
  • இந்த டெல்டாவின் புகழ்பெற்ற மாங்க்ரூவ் பகுதி? → சுந்தர்பன்ஸ்.
