1. அடிப்படைத் தகவல்கள்
  • ஒரு குறிப்புப் புள்ளியை ஒப்பிடும்போது காலத்துடன் ஒரு பொருளின் நிலை மாறுவது இயக்கம் எனப்படும்.
  • ஓய்வும் இயக்கமும் சார்புடைய கருத்துகள்.
  • ஒரு பொருள் ஒரு பார்வையாளரை ஒப்பிடும்போது ஓய்வில் இருக்கலாம்; மற்றொரு பார்வையாளரை ஒப்பிடும்போது இயக்கத்தில் இருக்கலாம்.
  • நிலை, தூரம், இடப்பெயர்ச்சி, வேகம், திசைவேகம் மற்றும் முடுக்கம் ஆகியவற்றின் மூலம் இயக்கம் விவரிக்கப்படுகிறது.
  • நீளத்தின் SI அலகு மீட்டர்.
  • நேரத்தின் SI அலகு வினாடி.
  • இயக்கம் சீரானதாகவோ சீரற்றதாகவோ இருக்கலாம்.
  • இயக்கம் இடமாற்று, சுழற்சி, வட்ட, அலைவு, காலமுறை அல்லது சீரற்ற இயக்கமாக இருக்கலாம்.
  • இயக்கத்திற்கான காரணங்களைப் பற்றி ஆராயாமல் இயக்கத்தை மட்டும் விவரிக்கும் இயக்கவியலின் பிரிவு இயக்கவிளக்கவியல்.
🔗 TNPSC Key Link

இயக்கம் → காலத்துடன் நிலை மாற்றம்

2. குறிப்புப் புள்ளி
  • ஒரு பொருளின் நிலை அல்லது இயக்கம் எதை ஒப்பிட்டு விவரிக்கப்படுகிறது என்பதைக் காட்டும் நிலையான புள்ளி குறிப்புப் புள்ளி.
  • குறிப்பு அமைப்பு அல்லது குறிப்புப் புள்ளி இல்லாமல் இயக்கத்தை பொருளுள்ளதாக விவரிக்க முடியாது.
  • நகரும் ரயிலில் அமர்ந்திருக்கும் பயணி ரயிலை ஒப்பிடும்போது ஓய்வில் இருக்கிறார்.
  • அதே பயணி தரையில் நிற்கும் ஒருவரை ஒப்பிடும்போது இயக்கத்தில் இருக்கிறார்.
⚠️ TNPSC Trap

சாதாரண இயக்கவியலில் ஓய்வும் இயக்கமும் சார்புடையவை; முழுமையானவை அல்ல.

3. நிலை
  • தேர்ந்தெடுக்கப்பட்ட ஆதாரப் புள்ளியை ஒப்பிடும்போது ஒரு பொருள் எங்கு உள்ளது என்பதை நிலை விவரிக்கிறது.
  • ஆய அச்சுகளைக் கொண்டு நிலையை விவரிக்கலாம்.
  • நிலையில் ஏற்படும் மாற்றம் இடப்பெயர்ச்சியை அளிக்கிறது.
  • தேர்ந்தெடுக்கப்பட்ட ஆய அமைப்பைப் பொறுத்து நிலை நேர்ம, எதிர்ம அல்லது பூஜ்யமாக இருக்கலாம்.
4. தூரம்
  • ஒரு பொருள் உண்மையில் கடந்த பாதையின் மொத்த நீளம் தூரம் எனப்படும்.
  • தூரம் ஒரு திசையிலி அளவு.
  • தூரத்திற்கு அளவு மட்டும் உள்ளது.
  • தூரம் எப்போதும் பூஜ்யம் அல்லது நேர்ம மதிப்பாக இருக்கும்.
  • தூரத்தின் SI அலகு மீட்டர்.
  • ஒரு பொருள் உண்மையில் சென்ற பாதையைப் பொறுத்தே தூரம் அமையும்.
🔗 TNPSC Key Link

தூரம் → உண்மைப் பாதை → திசையிலி

5. இடப்பெயர்ச்சி
  • ஆரம்ப நிலையிலிருந்து இறுதி நிலைக்கு உள்ள மிகக் குறுகிய நேர்கோட்டு திசை மாற்றம் இடப்பெயர்ச்சி.
  • இடப்பெயர்ச்சி ஒரு திசையன் அளவு.
  • இடப்பெயர்ச்சிக்கு அளவும் திசையும் இரண்டும் உள்ளன.
  • இதன் SI அலகு மீட்டர்.
  • ஒரு பரிமாண இயக்கத்தில் இடப்பெயர்ச்சி நேர்ம, எதிர்ம அல்லது பூஜ்யமாக இருக்கலாம்.
  • இடப்பெயர்ச்சி ஆரம்ப மற்றும் இறுதி நிலைகளை மட்டும் சார்ந்தது.
🔗 TNPSC Key Link

இடப்பெயர்ச்சி → மிகக் குறுகிய திசை மாற்றம் → திசையன்

6. தூரம் மற்றும் இடப்பெயர்ச்சி
  • தூரம் எப்போதும் இடப்பெயர்ச்சியின் அளவை விட அதிகமாகவோ அதற்கு சமமாகவோ இருக்கும்.
  • தூரம் ஒருபோதும் எதிர்மமாக இருக்க முடியாது.
  • தூரம் பூஜ்யமல்லாதபோதும் இடப்பெயர்ச்சி பூஜ்யமாக இருக்கலாம்.
  • திசை மாறாமல் நேர்கோட்டில் நகரும்போது தூரம் = இடப்பெயர்ச்சியின் அளவு.
  • ஒரு முழுச் சுற்றுப்பயணத்தின் முடிவில் இடப்பெயர்ச்சி பூஜ்யம்; ஆனால் தூரம் பூஜ்யமல்ல.
⚠️ TNPSC Trap

முழுச் சுற்றுப்பயணம் → இடப்பெயர்ச்சி = 0

தூரம் ≠ 0

7. எடுத்துக்காட்டு — வட்டப் பாதை
  • ஒரு ஓட்டப்பந்தய வீரர் ஒரு முழு சுற்றை முடித்து தொடக்கப் புள்ளிக்குத் திரும்புகிறார்.
  • ஒரு முழு சுற்றுக்குப் பிறகு இடப்பெயர்ச்சி பூஜ்யம்.
  • அவர் கடந்த தூரம் வட்டப் பாதையின் சுற்றளவுக்கு சமம்.
  • அரை வட்டச் சுற்றுக்குப் பிறகு இடப்பெயர்ச்சி வட்டத்தின் விட்டத்துக்கு சமம்.
8. வேகம்
  • தூர மாற்றத்தின் வீதம் வேகம் எனப்படும்.
  • வேகம் = தூரம் / நேரம்.
  • வேகம் ஒரு திசையிலி அளவு.
  • வேகத்தின் SI அலகு மீட்டர்/வினாடி.
  • அடிப்படை இயக்கவியலில் வேகம் எதிர்ம மதிப்பாக இருக்காது.
  • ஓய்விலுள்ள பொருளின் வேகம் பூஜ்யம்.
🔗 TNPSC Key Link

வேகம் → தூரம்/நேரம் → திசையிலி

9. திசைவேகம்
  • இடப்பெயர்ச்சியின் மாற்ற வீதம் திசைவேகம்.
  • சராசரி திசைவேகம் = இடப்பெயர்ச்சி / நேரம்.
  • குறிப்பிட்ட ஒரு கணத்தில் நிலை எவ்வளவு வேகமாக மாறுகிறது என்பதை உடனடி திசைவேகம் காட்டுகிறது.
  • திசைவேகம் ஒரு திசையன் அளவு.
  • இதன் SI அலகு மீட்டர்/வினாடி.
  • வேகம் அல்லது திசை இவற்றில் ஏதேனும் ஒன்று மாறினால் திசைவேகம் மாறும்.
🔗 TNPSC Key Link

திசைவேகம் → இடப்பெயர்ச்சி/நேரம் → திசையன்

10. வேகம் மற்றும் திசைவேகம்
  • வேகம் திசையிலி.
  • திசைவேகம் திசையன்.
  • வேகம் தூரத்தை அடிப்படையாகக் கொண்டது.
  • திசைவேகம் இடப்பெயர்ச்சியை அடிப்படையாகக் கொண்டது.
  • மாறாத வேகம் என்றாலே மாறாத திசைவேகம் என்று பொருளல்ல.
  • சீரான வட்ட இயக்கத்தில் வேகம் மாறாது; ஆனால் திசை தொடர்ந்து மாறுவதால் திசைவேகம் மாறிக்கொண்டே இருக்கும்.
⚠️ TNPSC Trap

வட்டத்தில் மாறாத வேகம் → திசைவேகம் மாறாதது அல்ல.

11. சராசரி வேகம்
  • சராசரி வேகம் = கடந்த மொத்த தூரம் / எடுத்த மொத்த நேரம்.
  • சராசரி வேகம் கடந்த மொத்த பாதை நீளத்தைச் சார்ந்தது.
  • சராசரி வேகம் பொதுவாக இரண்டு வேகங்களின் எண்கணித சராசரிக்குச் சமமல்ல.
  • சம தூரங்களை வெவ்வேறு வேகங்களில் கடக்கும் போது தனித்த கணக்கீடு தேவை.
12. சம தூரங்களுக்கான சராசரி வேகம்
  • சம தூரங்கள் u மற்றும் v வேகங்களில் கடக்கப்பட்டால், சராசரி வேகம் = 2uv/(u + v).
  • சம நேர இடைவெளிகள் போன்ற குறிப்பிட்ட சூழல்களில் மட்டுமே எண்கணித சராசரி பொருந்தும்.
📌 Remember

சம தூர சராசரி வேகம் → ஹார்மோனிக் வகை சராசரி

2uv/(u + v)

13. சராசரி திசைவேகம்
  • சராசரி திசைவேகம் = மொத்த இடப்பெயர்ச்சி / மொத்த நேரம்.
  • ஒரு பொருள் கணிசமான தூரம் பயணித்திருந்தாலும் அதன் சராசரி திசைவேகம் பூஜ்யமாக இருக்கலாம்.
  • தொடக்க இடத்திற்கே திரும்பும் மூடிய பயணத்தில் சராசரி திசைவேகம் பூஜ்யம்.
  • சராசரி வேகம் எப்போதும் சராசரி திசைவேகத்தின் அளவை விட அதிகமாகவோ அதற்கு சமமாகவோ இருக்கும்.
14. உடனடி வேகம்
  • ஒரு குறிப்பிட்ட கணத்தில் உள்ள வேகம் உடனடி வேகம்.
  • வாகனத்தின் வேகமானி உடனடி வேகத்தைக் காட்டுகிறது.
  • உடனடி வேகம் என்பது உடனடி திசைவேகத்தின் அளவு.
🔗 TNPSC Key Link

வேகமானி → உடனடி வேகம்

15. சீரான இயக்கம்
  • சம நேர இடைவெளிகளில் சம தூரங்களை கடக்கும் இயக்கம் சீரான இயக்கம்.
  • சீரான நேர்கோட்டு இயக்கத்தில் திசைவேகம் மாறாமல் இருக்கும்.
  • சீரான நேர்கோட்டு இயக்கத்தில் முடுக்கம் பூஜ்யம்.
  • சீரான இயக்கத்திற்கான தூரம்–நேரம் வரைபடம் மாறாத சாய்வு கொண்ட நேர்கோடு.
📌 Remember

சீரான நேர்கோட்டு இயக்கம் → மாறாத திசைவேகம் → a = 0

16. சீரற்ற இயக்கம்
  • சம நேர இடைவெளிகளில் சமமில்லாத தூரங்கள் கடக்கப்பட்டாலோ அல்லது திசை மாறினாலோ அது சீரற்ற இயக்கம்.
  • வேகம் அல்லது திசைவேகம் காலத்துடன் மாறும்.
  • முடுக்கமுள்ள இயக்கம் சீரற்ற இயக்கத்தின் ஒரு வடிவம்.
  • மாறாத வேகத்தில் நடைபெறும் வட்ட இயக்கத்திலும் திசை மாறுவதால் திசைவேகம் சீரற்றதாகும்.
17. முடுக்கம்
  • திசைவேகத்தின் மாற்ற வீதம் முடுக்கம்.
  • மாறாத முடுக்கத்திற்கு a = (v − u)/t.
  • முடுக்கம் ஒரு திசையன் அளவு.
  • இதன் SI அலகு m/s².

  • அதே விசைக்கு அதிக நிறை குறைந்த முடுக்கத்தை தரும்.
79. இயக்கம் மற்றும் ஆற்றல்
  • நகரும் பொருளுக்கு இயக்க ஆற்றல் உள்ளது.
  • KE = ½mv².
  • இயக்க ஆற்றல் வேகத்தின் வர்க்கத்தைச் சார்ந்தது.
  • அதே நிறைக்கு வேகம் இரட்டிப்பானால் இயக்க ஆற்றல் நான்கு மடங்காகும்.
  • ஒரு பொருளின் மீது வேலை செய்யப்படும்போது அதன் இயக்கம் மாறக்கூடும்.
80. வெற்றிடத்தில் இயக்கம்
  • வெற்றிடத்தில் காற்றுத் தடை இல்லை.
  • ஒரே இடத்தில் தடையின்றி விழும் அனைத்து பொருட்களும் ஒரே முடுக்கத்தில் விழுகின்றன.
  • வெற்றிடத்தில் இறகும் சுத்தியலும் ஒன்றாக விழும்.
  • சாதாரண காற்றில் விழும் வேக வேறுபாடுகளை காற்றுத் தடை விளக்குகிறது.
81. கலிலியோ மற்றும் இயக்கம்
  • கலிலியோ கலிலேய் இயக்கத்தின் அறிவியல் ஆய்வுக்கு முக்கிய பங்களிப்பு செய்தார்.
  • அவர் விழும் பொருட்களை ஆய்வு செய்தார்.
  • அவர் முடுக்கமுள்ள இயக்கத்தை ஆய்வு செய்தார்.
  • அவர் எறிபொருள் இயக்கத்தை ஆய்வு செய்தார்.
  • அவரது பணி இயக்கவிளக்கவியலுக்கான அடித்தளத்தை அமைத்தது.
  • அதிக நிறையுள்ள பொருட்கள் அவசியமாக வேகமாக விழும் என்ற நம்பிக்கையை கலிலியோ சவால் செய்தார்.

82. நியூட்டன் மற்றும் இயக்கம்
  • ஐசக் நியூட்டன் மூன்று இயக்க விதிகளை வகுத்தார்.
  • நியூட்டனின் முதல் விதி மந்தநிலையை விளக்குகிறது.
  • நியூட்டனின் இரண்டாம் விதி விசையையும் முடுக்கத்தையும் தொடர்புபடுத்துகிறது.
  • நியூட்டனின் மூன்றாம் விதி செயல் மற்றும் எதிர்செயலை விளக்குகிறது.
  • நியூட்டனின் விதிகள் பாரம்பரிய இயக்கவியலின் அடித்தளமாக உள்ளன.
83. வேகமானி
  • வேகமானி ஒரு வாகனத்தின் உடனடி வேகத்தை அளக்கிறது.
  • இது கடந்த தூரத்தை நேரடியாக அளப்பதில்லை.
  • வேகத்தின் SI அலகு m/s; ஆனால் வாகன வேகமானிகள் பொதுவாக km/h-ல் காட்டுகின்றன.

86. முடுக்கமானி
  • முடுக்கமானி முடுக்கத்தை அளக்கிறது.
  • முடுக்கமானிகள் ஸ்மார்ட்போன்கள், வாகனங்கள் மற்றும் வழிசெலுத்தல் அமைப்புகளில் பயன்படுத்தப்படுகின்றன.
  • மற்ற உணரிகளுடன் சேர்ந்து பயன்படுத்தும்போது திசையமைப்பு மற்றும் இயக்க மாற்றங்களை கண்டறிய முடியும்.
87. சீரான முடுக்க வரைபடம்
  • திசைவேகம்–நேரம் வரைபடத்தில் மாறாத முடுக்கம் நேர்கோட்டை தரும்.
  • அதன் சாய்வு முடுக்கத்திற்கு சமம்.
  • அதிக நேர்ம சாய்வு அதிக நேர்ம முடுக்கத்தை குறிக்கிறது.
  • பூஜ்ய சாய்வு பூஜ்ய முடுக்கத்தை குறிக்கிறது.
88. ஓய்வு
  • தேர்ந்தெடுக்கப்பட்ட குறிப்பு அமைப்பை ஒப்பிடும்போது காலத்துடன் ஒரு பொருளின் நிலை மாறாமல் இருந்தால் அது ஓய்வில் உள்ளது.
  • ஓய்வு சார்புடையது.
  • நகரும் பேருந்தில் அமர்ந்திருப்பவர் பேருந்தை ஒப்பிடும்போது ஓய்வில் இருப்பார்; சாலையை ஒப்பிடும்போது இயக்கத்தில் இருப்பார்.
89. இயக்க வகைப்பாடு — நினைவில் கொள்ளவும்
  • நேர்கோட்டு பாதை → நேர்கோட்டு இயக்கம்.
  • வளைந்த பாதை → வளைந்த பாதை இயக்கம்.
  • வட்டப் பாதை → வட்ட இயக்கம்.
  • ஒரு அச்சைச் சுற்றி → சுழற்சி இயக்கம்.
  • நிலையான நேர இடைவெளிகளில் மீண்டும் நடைபெறும் → காலமுறை இயக்கம்.
  • சராசரி நிலையைச் சுற்றி முன்னும் பின்னும் → அலைவு இயக்கம்.
  • ஒழுங்கற்ற, கணிக்க முடியாத பாதை → சீரற்ற இயக்கம்.
90. முக்கிய இயக்கச் சூத்திரங்கள்
  • வேகம் = தூரம்/நேரம்.
  • சராசரி வேகம் = மொத்த தூரம்/மொத்த நேரம்.
  • சராசரி திசைவேகம் = மொத்த இடப்பெயர்ச்சி/மொத்த நேரம்.
  • முடுக்கம் = திசைவேக மாற்றம்/நேரம்.
  • v = u + at.
  • s = ut + ½at².
  • v² = u² + 2as.
  • s = (u + v)t/2.
  • மையநோக்கு முடுக்கம் = v²/r.
  • மையநோக்கு விசை = mv²/r.
  • கோண திசைவேகம் = θ/t.
  • நேர்கோட்டு வேகம் = rω.
  • அதிர்வெண் = 1/T.
  • எறிபொருளின் பறக்கும் நேரம் = 2u sinθ/g.
  • எறிபொருளின் அதிகபட்ச உயரம் = u²sin²θ/2g.
  • எறிபொருளின் கிடைமட்டத் தூரம் = u²sin2θ/g.

93. TNPSC Traps
  • இயக்கத்தை விவரிக்க ஒரு குறிப்புப் புள்ளி தேவை.
  • தூரம் பூஜ்யமல்லாதபோதும் இடப்பெயர்ச்சி பூஜ்யமாக இருக்கலாம்.
  • தூரம் திசையிலி.
  • இடப்பெயர்ச்சி திசையன்.
  • வேகம் திசையிலி.
  • திசைவேகம் திசையன்.
  • சராசரி வேகம் எப்போதும் வேகங்களின் எண்கணித சராசரி அல்ல.
  • சராசரி வேகம் பூஜ்யமல்லாதபோதும் சராசரி திசைவேகம் பூஜ்யமாக இருக்கலாம்.
  • மாறாத வேகம் என்றாலே மாறாத திசைவேகம் என்று பொருளல்ல.
  • சீரான வட்ட இயக்கத்தில் முடுக்கம் உள்ளது.
  • திசை மட்டும் மாறினாலும் முடுக்கம் ஏற்படலாம்.
  • எதிர்ம முடுக்கம் என்றாலே எப்போதும் வேகம் குறையும் என்று பொருளல்ல.
  • தூரம்–நேரம் வரைபடத்தின் சாய்வு வேகத்தை அளிக்கிறது.
  • இடப்பெயர்ச்சி–நேரம் வரைபடத்தின் சாய்வு திசைவேகத்தை அளிக்கிறது.
  • திசைவேகம்–நேரம் வரைபடத்தின் சாய்வு முடுக்கத்தை அளிக்கிறது.
  • திசைவேகம்–நேரம் வரைபடத்தின் பரப்பளவு இடப்பெயர்ச்சியை அளிக்கிறது.
  • வேகம்–நேரம் வரைபடத்தின் பரப்பளவு தூரத்தை அளிக்கிறது.
  • எறிபொருளின் அதிகபட்ச உயரத்தில் செங்குத்து திசைவேகம் பூஜ்யம்; ஆனால் முடுக்கம் g கீழ்நோக்கி இருக்கும்.
  • சமதளத்தில் எறிபொருளின் அதிகபட்ச கிடைமட்டத் தூரம் 45°-ல் கிடைக்கும்.
  • சிறந்த நிபந்தனைகளில் நிரப்பு எறிகோணங்கள் ஒரே கிடைமட்டத் தூரத்தை தரும்.
  • வெற்றிடத்தில் தடையற்ற வீழ்ச்சி முடுக்கத்தை நிறை பாதிக்காது.
  • செங்குத்தாக மேலே எறியப்பட்ட பொருளின் அதிகபட்ச உயரத்தில் முடுக்கம் பூஜ்யமல்ல.
  • வேகமானி வேகத்தை அளக்கிறது.
  • ஓடோமீட்டர் தூரத்தை அளக்கிறது.
  • டாக்கோமீட்டர் சுழற்சி வேகத்தை அளக்கிறது.
  • எதிர்திசை சார்பு வேகம் = வேகங்களின் கூட்டுத்தொகை.
  • ஒரே திசை சார்பு வேகம் = வேகங்களின் வேறுபாடு.
